# 一、实验目的

## 1. 掌握四类电机设备基础理论知识

通过数字孪生虚拟场景，系统学习变压器、异步电机、同步电机、直流电机四类设备的基础定义、内部结构、主要分类以及特点与应用。进入场景后先由导航页了解各区域分工，再分别进入设备认知区域，通过基本介绍、结构展示、工作原理等子模块展开学习，异步电机还额外包含绕组设计内容。学生结合三维模型、爆炸拆分视图、语音讲解与原理视频，建立对电机设备的直观认知，巩固电机学课程书本与课件理论知识，厘清四类电机在工作机理与结构组成上的差异，理解各类设备的适用场合与优缺点，为后续装配、接线与实验操作打下扎实的理论基础。

## 2. 熟悉虚拟仿真软件操作环境

掌握软件场景漫游操作，进入场景先通过导航页了解各功能区域的分工。熟练使用键盘“W”“A”“S”“D”四个按键在场景中移动，在左侧第一人称模式与漫游模式之间切换；学会鼠标右键拖动对三维模型进行360°旋转查看。在结构展示中掌握通用交互方式：从左侧部件列表选择零部件，被选部件高亮、其余部件透明化，右侧显示部件介绍并可点击语音按钮收听讲解，通过透明度滑块调节，在整体模式与拆分（爆炸图）模式之间切换。同时熟悉原理视频的暂停、快进与音量调节，以及答题模块、实验报告提交与下载等界面入口的位置与作用。

## 3. 完成设备组装、接线与故障排查实训

完成异步电机、变压器、同步电机、直流电机的虚拟组装任务：先完成异步电机，再按界面提示依次完成变压器、同步电机、直流电机，通过拖动对应零部件按装配顺序完成整机组装并对照结构进行校验。异步电机在组装完成后开展正反转接线，接线完毕进行运行测试；本环节设置典型故障案例，学生需掌握异步电机星形（Y）与三角形（Δ）接法的排查方法，理解接线错误带来的运行异常现象。通过反复练习建立工程实操思维，熟悉电机现场生产实习从装配、接线、测试到排故的基础流程与规范，养成按引导步骤操作、发现问题及时定位的习惯。

## 4. 完成仿真实验与数据处理

完成变压器短路实验、异步电机堵转实验、直流电机串电阻启动实验三项仿真实验。每项实验先阅读右侧实验原理与接线图建立初步认识，再跟随左侧操作步骤完成接线、通电、参数调节，采集仿真实验数据，由系统根据数据自动生成对应特性曲线，实验数据与曲线自动留存并在提交报告时汇入报告。学生借此理解各实验的原理与目的，掌握数据记录、读取与分析方法，能够对照曲线判断参数变化规律，并配合完成线上答题，最终汇总形成实验报告输出。

# 二、设备认知模块

## 1. 异步电机设备认知

异步电机又称感应电机，依靠定子旋转磁场与转子绕组感应电流产生电磁转矩实现能量转换，是工业中使用最广泛的交流电机。其内部主要包含接线盒、机座、前端盖、前轴承、风扇罩、风扇、后端盖、后轴承、定子、转子、带轮等11个零部件。按转子结构分为笼型（鼠笼式）异步电机与绕线转子异步电机；按相数分为单相、三相异步电机，工业生产以三相为主。异步电机结构简单、运行可靠、造价低廉、维护量小，大量用于风机、水泵、机床、传送带等工业拖动场合；不足在于功率因数偏低，普通笼型电机调速性能弱于直流电机。本模块提供基本介绍、结构展示、工作原理、绕组设计四项学习内容，支持模型旋转、透明度调整、爆炸拆分与语音讲解，可完成定子绕组参数设置与绕组搭建练习。

## 2. 变压器设备认知

变压器是基于电磁感应定律实现交流电压变换的静止电气设备，在两个无电气直接连接、仅靠磁场耦合的绕组之间传递交流电能或电信号，变换电压、电流大小而不改变交流电频率。其内部构件包含铁芯、高压绕组、低压绕组、油枕、油箱、散热器、高压套管、低压套管、调压控制箱、瓦斯继电器、吸湿器、低压绝缘纸、低压绝缘筒、高压绝缘筒、高压绝缘纸、上夹件、下夹件等18个部件。按用途分为电力变压器与特种变压器；按冷却方式分为油浸式与干式变压器。变压器具备电压变换、阻抗变换功能，运行可靠、效率较高，广泛应用于电力系统输配电环节。本模块提供基本介绍、结构展示、工作原理三项内容，配合文本资料、三维结构查看、爆炸图、语音讲解与原理视频，帮助学生理解电磁感应工作机理。

## 3. 同步电机设备认知

同步电机的转子转速与定子旋转磁场转速严格相等（同步运行），转子需通入励磁电流建立磁场，分为同步发电机与同步电动机。其内部结构包含定子铁芯、定子绕组、机座、端盖、轴承、转子铁芯、励磁绕组、风扇、风扇罩、接线盒、直流电刷、阻尼线圈、带轮等13个部件。按转子结构分为凸极式与隐极式同步电机；按用途分为发电机、电动机、调相机。同步发电机是电网的主要发电设备；同步电动机功率因数可调，多用于大功率恒速拖动场景，其中凸极式多用于水轮发电机，隐极式多用于汽轮发电机。本模块提供基本介绍、结构展示、工作原理三项内容，可查阅理论资料、三维查看零部件并观看工作原理视频。

## 4. 直流电机设备认知

直流电机依靠电枢与主磁极磁场相互作用实现机电能量转换，既可作电动机也可作发电机，依靠换向器完成电枢绕组电流方向的适时换向。其主要零部件有风机、前端盖、电刷、后端盖、换向器、电枢铁芯、电枢绕组、主磁极、换向极、励磁绕组、转轴、机座等12个部件。按励磁方式分为他励、并励、串励、复励直流电机。直流电机调速性能优异、可实现平滑调速且启动转矩大，多用于对调速要求高的拖动场合；缺点是需要换向器与电刷，结构较复杂、维护工作量较大。本模块包含基本介绍、结构展示、工作原理三项内容，支持理论文本学习、三维结构交互学习与工作原理视频学习。

## 5. 电机定子绕组基础知识点

定子绕组是电机实现机电能量转换的核心部件。绕组设计需要先确定槽数、极数、相带，计算槽距角，完成槽号分配，最后进行绕组搭建。槽距角计算公式为 a = P×360°／Q，辐射线数目 N = Q／P，其中Q为槽数、P为极对数。绕组参数直接影响电机电动势、磁动势的波形与电机运行性能，是异步电机重要的理论知识点。在虚拟仿真中，学生先学习定子绕组知识点，再进行绕组参数设计、展开图谱搭建与绕组搭建，并完成接线方案、槽位层别、线圈节距、重复占用、三相完整性等校验，校验通过后即完成绕组设计。

# 三、生产实习模块

## 1. 电机虚拟组装操作要点

进入生产实习模块后，学生需要拖动对应零部件，按设备装配逻辑顺序完成异步电机、变压器、同步电机、直流电机的整机组装。组装时可对照设备认知模块的三维结构与部件列表进行参考，逐一确认零部件的安装位置与配合关系，避免漏装、错装；零部件到位后完成整机校验。模块先完成异步电机的组装，再依次完成变压器、同步电机、直流电机的组装，全部设备组装完成后，方可进入后续课程实验环节，以此培养按工艺顺序规范操作的习惯。

## 2. 异步电机正反转接线与星三角故障处理

异步电机组装完成后开展正反转接线，接线完毕进行运行测试，观察电机转向是否符合接线要求。本模块设置典型故障案例：电机本应采用三角形（Δ）接法，但接线盒内铜片错误接为星形（Y）接法，电机启动时系统弹出故障提示框，指出故障所在并说明异常现象。学生不能仅停留在查看提示，而需要进入接线盒手动调整铜片接法，将星形改为三角形，排除故障后使电机能够正常启动运行。通过该案例理解星形—三角形接法的工程意义，掌握接线错误由提示定位、手动恢复的排查思路与操作方法。

# 四、课程设计及拓展模块

## 1. 变压器短路仿真实验

进行变压器短路实验时，先阅读界面右侧的实验原理与接线图，熟悉短路实验理论；再参照左侧操作指引完成接线、通电、参数调节，采集仿真实验数据，系统自动生成对应特性曲线。短路实验在副边短路的状态下，由原边通入较低电压使电流达到额定值，用于测定变压器短路阻抗、短路损耗等短路参数，为变压器运行与等效电路分析提供依据。实验过程中应按步骤规范接线并记录各测量点数据，实验数据与曲线会自动保存，用于后续生成实验报告。

## 2. 异步电机堵转仿真实验

学习堵转实验原理与接线方式，跟随左侧操作步骤完成接线、通电，调节实验参数获取堵转工况下的实验数据，系统生成特性曲线。堵转实验模拟电机转子被机械卡住、不能转动的工况，此时转子不动、不产生感应旋转运动，原理上类似变压器副边短路，用于获取异步电机短路参数并分析其堵转特性。实验过程中应按步骤规范接线并逐点记录数据，实验数据自动留存供实验报告调用，学生应重点关注不同参数下电流、转矩的变化规律，并结合生成的曲线进行分析。

## 3. 直流电机串电阻启动仿真实验

通过操作虚拟控制箱的旋钮与按钮选择对应实验项目，调节直流电机电压，观察面板上电流等参数的实时变化，采集实验数据并生成特性曲线。直流电机直接启动时启动电流较大，串电阻启动通过在电枢回路串入启动电阻限制启动电流、实现平滑启动，待转速上升后逐级切除电阻。学生应理解串电阻启动的原理，掌握直流电机启动过程中电压、电流等参数的变化规律，观察面板数值随调压的对应变化，并结合生成的特性曲线完成分析与记录。

## 4. 在线答题与实验报告提交

全部仿真实验完成后，点击界面上方答题按钮进入答题界面，系统从题库随机抽取试题，每名学生拿到的题目都不相同，提交答案后系统给出题目解析，供学生核对与复习。全部环节完成后提交实验报告，报告包含各环节得分、实验原始数据与生成曲线，提交成功后支持下载查看，学生可在报告中逐项核对自己的操作得分、原始记录与曲线，了解薄弱环节。仿真系统对设备认知、组装、实验、答题各个环节独立评分，最终在实验报告中汇总给出每个环节的分数，实现过程性考核与学习效果评价。
