# 一、槽式光热发电系统认知

## 1. 实验目的与教学目标

依托虚拟仿真直观性优势，使用户掌握风光热电储各系统核心原理，熟悉聚光槽、储热罐、汽轮发电机等关键设备结构及工作机制，掌握多能源联供系统的组成逻辑与运行流程，实现理论知识与虚拟实操的深度融合。能力层面培养基于时间、季节、地域等维度的能源需求分析能力，提升设备选型、参数配置及搭建验证的工程实践能力。素质层面树立"双碳"目标下的绿色能源责任意识，培养严谨务实的工程素养与团队协作精神。

## 2. 槽式光热发电基本原理

槽式光热发电利用槽型抛物面反射镜将太阳直射辐射汇聚到焦线处的集热管上，加热管内传热工质，再通过换热环节产生高温高压蒸汽驱动汽轮发电机组发电。系统主要由两大部分组成：一是由聚光槽、储热罐、熔融盐、熔盐泵构成的太阳能集热场；二是一套传统汽轮机发电装置，包括汽轮机、发电机、凝汽器、给水泵。二者通过蒸发器连接，形成"聚光—集热—储热—换热—发电"的完整工艺链。

## 3. 能量转换主线与系统闭环

槽式系统的能量转换路径为：太阳辐射能 → 聚光槽汇聚 → 集热管内传热工质吸热 → 高温熔融盐输送与储存 → 蒸发器换热产生蒸汽 → 汽轮机做功 → 发电机输出电能。做功后的蒸汽在凝汽器中冷凝为水，经给水泵送回蒸发器再次吸热，构成封闭循环。储热环节使集热与发电在时间上解耦，可在太阳辐射不足时继续供热发电，是本系统区别于纯光伏发电的重要特征。

## 4. 软件中的场景构成与槽式定位

软件的场景搭建模块分为三个不同场景：塔式光热发电场景，搭配吸收式制冷机；槽式光热发电场景，搭配吸收式制冷机；光伏发电系统场景，搭配风力发电机、板式太阳能集热器、储能电站等设备。本知识库对应槽式光热发电场景，教学重点是槽式聚光集热、熔盐传热储热与汽轮机发电三个环节的设备构成与工艺关系，配套设备为吸收式制冷机，用于认识汽轮机余热利用路径。

# 二、槽式光热发电核心设备

## 1. 聚光槽

聚光槽即槽式抛物面聚光器，是利用槽型抛物面反射镜将太阳光聚集反射到管状集热管上的装置。其结构由反射镜阵列、真空集热管、跟踪系统和支撑结构四部分组成：反射镜阵列负责将太阳光聚焦于真空集热管，集热管位于焦点位置、内部填充传热流体，跟踪系统随太阳位置调整镜面朝向，支撑结构承受风、雪、地震等环境载荷。教学重点在于理解线聚焦方式与塔式点聚焦的区别。

## 2. 单轴跟踪系统

单轴跟踪系统用于定位和调整聚光槽的方向，以最大化捕捉太阳辐射能量。其工作原理是：由 PC 机、PLC 或单片机等控制部件计算太阳高度角或方位角并发出控制指令，传动机构将指令转化为集热器的实际转动，传感器测量聚光槽角度并反馈给控制部件，形成闭环调节。与双轴跟踪相比，单轴跟踪结构简单、制造成本较低，适合槽式这类沿单一转轴调整的线聚焦装置，本项目槽式系统即采用单轴跟踪。

## 3. 集热管与传热工质

真空集热管位于反射镜阵列的焦点位置，内部填充传热流体，负责吸收聚焦后的太阳辐射并将热量输出至后续环节。集热管外的真空夹层用于抑制对流与导热损失，提高集热效率。传热工质早期多采用导热油，工作温度较低，导致发电机组效率远低于常规火电站；改用熔融盐作为高温传热储热介质后，工作温度可提升至 550℃ 以上，在聚光集热条件相同的前提下能大幅提高发电效率与年发电量。

## 4. 熔融盐

光热电站常用熔融盐分为二元混合盐与三元混合盐：二元盐为 60% 硝酸钠与 40% 硝酸钾的混合熔盐，三元盐为 53% 硝酸钾、7% 硝酸钠与 40% 亚硝酸钠。硝酸熔盐比热容大、导热系数大，常压下熔点约 220℃、气化温度约 600℃，粘度小，稳定性好、不可燃、无爆炸危险，泄漏蒸汽无毒，既是储热介质也是传热介质。熔盐通过升温或降温实现热能存储，过程中不发生相变。

## 5. 熔盐泵

熔盐泵用于输送高温熔融盐，属于离心泵，依靠叶轮高速旋转使液体在惯性离心力作用下被甩出，从而完成输送。系统中最主要的是熔盐罐用泵，采用立式悬吊结构，从罐顶插入罐体，驱动电机与熔盐出口位于罐顶上部，泵体接近罐底、浸在高温熔盐中，故称高温熔盐液下泵。按叶轮层数分为多级泵，槽式系统一般采用 2 级或 3 级熔盐泵即可满足熔融盐流动需求。

## 6. 储热罐与双罐储热系统

熔融盐温度高且具有腐蚀性，储罐内衬采用耐高温、耐腐蚀、机械强度足够的奥氏体不锈钢板，内衬外周与底面砌隔热耐火砖，外部为碳钢外壁，内衬顶面铺硅酸铝棉毡保温，罐底设泡沫玻璃与沙粒组成的保温层，并用电加热器维持罐内熔盐温度以防凝固。系统按流程设冷、热两个熔盐储罐，构成双罐储热：冷罐约 290℃，热罐约 565℃，热盐经熔盐泵送入换热器生产高压过热蒸汽后回到冷罐循环。

## 7. 换热器与蒸发器

系统采用管壳式 U 型管换热器，由外壳、换热管、固定管板、折流板、管箱等组成，结构简单、制造容易，打开前后管箱即可对换热管进行机械清洗，缺点是壳程无法机械清洗，要求壳程流体流动性好、不结垢。蒸发器与管壳式换热器结构类似、原理相同，用于将液体加热沸腾产生蒸汽。本项目展示釜式蒸发器，由壳体、U 型换热管束、管箱组成，热源流体走管程，被加热的水在壳体内，壳体上部留出蒸汽分离空间。

## 8. 汽轮发电机

蒸发器产生的一定温度、压力的蒸汽进入汽轮机膨胀加速，带动汽轮机与发电机转子高速旋转。发电机转子由铁芯与绕组组成，励磁直流电源送入转子线圈使其成为电磁铁并产生旋转磁场；定子绕组中的导体切割磁力线产生感应电动势，经内部电路与外部负载形成电流，完成机械能到电能的转换。电能经变压器升压后由输电线路送至电网。教学中应区分蒸汽热能输入、汽轮机机械做功与发电机电能输出三个环节。

## 9. 凝汽器与冷却塔

凝汽器是将汽轮机排汽冷凝成水的换热器，又称复水器，按冷却方式分为水冷凝汽器与空冷凝汽器，本项目采用水冷凝汽方式。除完成排汽凝结外，凝汽器在本系统中还承担供热职责：高温水蒸气进入换热器加热储热系统的供回水，供回水再流入教学楼毛细管空调系统供暖；凝结水与剩余蒸汽被收集并全部转换为水，返回系统参与下一次循环。冷却塔则服务于冷却水侧的散热，维持冷端真空。

# 三、储热、储电与储冷系统

## 1. 储热系统的两种供热方式

储热系统涉及熔融盐、储热罐、储热水箱、板式太阳能集热器、换热器、毛细管墙壁等设备，既为光热发电系统和用户提供热量，也具备储热能力，在无法直接从太阳获取能量时启动储热装置为系统提供动力。软件设计了两种供热方式：一是借助汽轮机蒸汽余热为教学楼提供热水，以熔融盐为导热介质、储热罐承担储热功能；二是通过板式太阳能集热器直接加热水并储存于储热水箱。

## 2. 板式太阳能集热器

板式太阳能集热器是太阳能热利用系统的基本部件。工作时太阳辐射穿过透明盖板投射到吸热板上，吸热板多采用铜等高导热材料并涂覆深色吸收涂层，将辐射能转换为热能后传给板内流动的传热介质，升温后的介质从出口流出并蓄入储水箱待用。集热器还包括透明盖板、隔热层和外壳：盖板透光并保护吸热板、与外壳构成温室环境减少对流与辐射损失，隔热层抑制导热散热。因不具备聚光能力，效率有限，多用于热水供应。

## 3. 储热水箱

储热水箱基于储存与保温热水的功能工作，通常由外壳、内胆和绝热材料组成。热水经管道从供应源流入内胆，绝热材料如聚苯乙烯泡沫置于内胆与外壳之间，防止热量散失，使热水在储存期间保持一定温度。用户需要热水时开启给水泵，热水从内胆流出供应使用，流出的热水由冷水补充，水箱随后重新加热新的冷水。水箱一般配备温度传感器与温度控制装置，监测并调节水温，使其保持在所需范围内。

## 4. 毛细管墙壁

毛细管墙壁空调系统是一种新型辐射空调系统，基于仿生学原理模拟人体血液从心脏到末端毛细血管的循环形态，以辐射换热方式使建筑环境与人体、物体之间达到热平衡。系统核心组件包括热交换器、分集水器、温控调节系统、毛细管网末端及配套除湿系统，末端通常铺设于墙壁、顶棚或地板内。相比传统空调，其热交换面积大、供水温度要求低而节省能源，无吹风感、舒适度高，占用空间小、使用寿命长。

## 5. 储能电池

本项目储能电站采用三元锂电池，新能源汽车采用磷酸铁锂电池。磷酸铁锂电池以磷酸铁锂为正极材料，充放电基于锂离子在正负极间的嵌入与脱出：充电时外部电源迫使电子由负极流向正极，锂离子经电解液从负极（通常为石墨）移动到正极并嵌入磷酸铁锂结构；放电时过程反向，锂离子脱出回到负极，电子经外电路为负载供电。该可逆过程使电池可重复使用，具有能量密度较高、寿命长、安全性好、环保等优点。

## 6. 动力电池及与储能电池的区别

动力电池为新能源汽车整车驱动及其他用电器提供电能，由电芯经串联、并联或混联组成电池模组，再组成电池包；电芯含正极、负极、电解液和外壳，依靠锂离子迁移实现充放电。主流类型有三元锂电池、磷酸铁锂电池、镍氢电池、燃料电池等，性能参数包括充电终止电压、放电终止电压、荷电状态（SOC）、标称容量与实际容量、能量密度和功率密度。与储能电池相比，动力电池更强调高倍率充放电与能量密度，储能电池更强调长循环寿命与成本控制。

## 7. 变压器、整流器与逆变器

变压器基于电磁感应工作：一次侧绕组加交流电压后在铁芯中产生交变磁通，穿过二次侧绕组感应出电动势，通过改变匝数比实现升压或降压，用于变换交流电压、电流和阻抗。整流器利用半导体器件的单向导电性将交流电转换为直流电，正向电压导通、反向电压截止。逆变器则将直流电转换为交流电，利用 IGBT 或 MOSFET 的开关特性，将直流电分成脉冲信号再经滤波调整，输出所需频率、幅值和波形的交流电，常配电池管理系统监控充放电状态。

## 8. 吸收式制冷机与耗电式制冷机

吸收式制冷机利用溶液在一种条件下析出低沸点组分蒸气、在另一条件下又能吸收该组分的特性完成制冷循环。它由发生器、冷凝器、吸收器和蒸发器四大部件组成，形成制冷剂循环与吸收剂循环两个环路：吸收剂吸收蒸发器产生的低压气态制冷剂形成溶液，加热后释放高压气态制冷剂；高压制冷剂在冷凝器中冷凝、节流降压后进入蒸发器蒸发制冷。该机型以热能驱动，可消纳汽轮机余热。耗电式制冷机即压缩式制冷机，由压缩机、冷凝器、节流装置和蒸发器构成，以电能驱动。

## 9. 乙二醇水溶液与储冷水箱

储冷系统以乙二醇水溶液作为载冷剂，其亲水性好、可与水充分混合形成透明无色液体，凝固点低、低温下保持液态而避免冻结，化学稳定性与热传导性能良好，可在较宽温度范围内稳定传热。乙二醇水溶液被冷却后循环通过储冷装置中的换热器，将冷量传递给其他介质实现冷量储存；使用时泵出与水换热，由水进入毛细管系统为教学楼制冷。需注意乙二醇具有毒性，使用中应做好防护并定期维护其浓度与质量。储冷水箱则由外壳、内胆与绝热材料组成，配温度传感器与控制装置维持低温。

# 四、虚拟仿真软件操作

## 1. 软件启动与基础操作

软件采用 B/S 架构，兼容多浏览器及 Windows 系列操作系统，可局域网部署；支持在 Windows 8/10/11 及 Windows Server 系列系统下运行，可通过谷歌浏览器、火狐浏览器、Microsoft Edge 访问指定地址。进入软件首页后点击"开始实验"，选择新建实验项目即可进入虚拟工厂场景。关闭时可直接关闭浏览器页面，或点击界面中的"退出软件"按钮。主菜单栏设有"软件简介""操作简介"按钮，以图文解说形式展示软件功能与操作方法。

## 2. 设备认知操作

设备认知模块先介绍我国目前的能源结构，再以"沉浸式交互+知识拆解"方式完成各系统核心设备的深度认知，覆盖发电、储能、传输全链条。每个设备支持 360° 旋转观察，采用三维展示、高亮透明、局部结构查看等多维度交互方式；点击功能按钮可触发系统原理动画，动画伴随语音介绍和文字说明，既有宏观的设备运行原理演示，也有微观角度的运行动画。风力、光伏、储能三个系统另设性能曲线界面，可观察各参数的变化关系。

## 3. 场景搭建操作

场景搭建模块基于"需求导向—方案设计—优化迭代"的工程逻辑，帮助用户完成多能源联供系统的虚拟搭建。进入模块后首先弹出文本介绍窗口，展示模块介绍、实习场景与实习任务；随后进入校园场景 45° 俯视图，图中分布各待搭建设备，点击设备即可进入场景，从屏幕右侧设备库将设备手动拖入场景。搭建完成后弹出系统参数设置界面，供用户手动设置各设备参数。全部设置完成后系统完成场景搭建，用户即可在场景中漫游。

## 4. 场景漫游与 DCS 监控

完成设备搭建进入场景后，以第一人称视角在虚拟工厂场景中漫游：按 W、A、S、D 键实现前进、后退、向左、向右移动，鼠标左键拖动转动视角，按 F 键切换飞行/步行模式。漫游时可点击所要了解的设备，弹出学习内容选择菜单，选择后可学习设备原理与结构介绍，并触发原理讲解图文弹窗。通过 DCS 界面可监控整个场景中各设备的参数变化，观察设备位置布局、流体流动方向与设备间连接关系。

## 5. 二维自由搭建与端口连接

生产实习模块通过二维自由搭建对前面学习的各系统设备进行仿真。用户从屏幕左侧设备库中选择合适设备拖入中间画布，单击设备图标可对其参数进行详细设置。设备图标两侧带有代表熔融盐、蒸汽、水、AC 或 DC 的接口，左侧接口代表输入、右侧接口代表输出，输入与输出的接口必须是相同类型，连接错误则无法建立有效拓扑。搭建完成后可查看系统运行结果与曲线，理解能量转换系统的基本拓扑关系。

## 6. 课程设计模块

课程设计模块通过文案介绍、曲线图变化和数据变化，向用户介绍不同控制策略下离网风光储系统的表现。学习重点在于将控制策略与系统输出曲线、运行数据对应起来，理解策略差异对系统运行的影响，而不是自行编写控制算法。该模块属于既有策略展示，不对应自动寻优、经济性优化等扩展功能。

## 7. 理论考核

理论考核模块聚焦核心理论知识，采用"分层出题+自动判分"模式。软件内置大容量题库，用户答题时系统自动随机抽取 10 道单选题和 10 道多选题组成试卷。完成试卷后若对作答没有信心，可点击"重新考试"按钮重新生成一份不同的试卷；确认提交则点击"提交"按钮上传答题。系统自动根据答题情况评分并展示错题解析，答题情况会被保存在实验报告中。

## 8. 实验评分与实验报告

实验过程中系统自动记录用户操作数据，完成后进入评分模块。考核内容包含实验步骤考核与实验数据考核，融合单选、多选、自组卷等考题形式；评分按操作步骤完成度、参数调试合理性、考题作答正确率综合评定，支持按步骤单独评分与整体综合评分。点击"评价"按钮可查看详细评分内容，含操作亮点与改进建议；点击"提交结果"完成成绩提交。系统自动生成实验报告并支持下载，内容含生产实习与理论考核得分、系统运行图表与转换场景；教师可线上批阅。

# 五、实验步骤与实验评价

## 1. 第一步：需求分析

对风光热电储一体化场景进行选择，根据不同时间、季节、地域跨度进行多维度需求分析。时间维度：白天使用光热发电发热、光伏发电、风力发电；黑夜依靠储热发电、储电释放、风力发电；特殊情况下可直接使用市电。季节维度：春季光照强度与日照时间中等，供热、制冷均有需求；夏季光照强度高、日照时间长，制冷需求高；秋季与春季相近；冬季光照强度低、日照时间短，供热需求高。地域维度：固定选择多个地点，其差异体现在光照强度、昼夜时间、年均温度与风速。

## 2. 第二步：多能源联供储能系统设计

针对选定场景及能源需求，进行联供储能系统的二维设计及搭建。用户需要考虑：建设的综合系统在白天能够生产并储存多少热熔盐；光伏发电系统与风力发电系统能够生产多少电量；这些供给能否全天满足用户能源需求；是否需要接入市电支援。设计时需按介质与电气类型正确连接端口，保证拓扑合理、参数配置与需求匹配，并预留必要的容量裕度。

## 3. 第三步：多能源联供储能系统验证

在不同负荷条件下进行系统验证实验，检验白天依靠光伏发电、光热发电、风力发电产生的电能是否满足用户需求，夜晚依靠风力发电和储能能否满足用户需求。验证时需结合 DCS 界面与运行曲线观察各设备参数变化，判断系统在昼夜、季节切换下的供能平衡情况，找出供给不足或设备配置不合理的环节并返回调整设计。

## 4. 实验评价指标与评分构成

实验评价构建"过程+结果"双维度体系。过程性评价 60 分：系统自动记录设备认知测试成绩、场景搭建方案合理性、生产实习操作规范性、理论考核成绩，实时生成过程得分曲线。结果性评价 40 分：结合实验报告与教师主观评分，聚焦实验思路创新性与问题解决逻辑性。评价完成后生成综合成绩单，标注薄弱环节并提供学习建议，支持教师导出班级评价数据。按实验步骤划分的评分参考为：设备结构认知 25 分、设备原理学习 25 分、用户需求分析 10 分、系统搭建及验证 40 分。
