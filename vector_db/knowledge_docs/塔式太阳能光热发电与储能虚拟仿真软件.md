# 一、实验定位与学习目标

## 1. 实验对象与系统边界

本实验以塔式太阳能光热发电与储能系统为对象，研究太阳辐射经定日镜场聚光、塔顶吸热、熔融盐传热及储热、蒸汽动力循环发电的过程，同时认识余热供暖和吸收式制冷等热能利用环节。实验面向大型光热电站不便在课堂中反复操作的高温、高压及复杂工艺，将设备认知、三维场景搭建、二维工艺自由搭建、运行仿真与考核评价连接起来。其核心是塔式光热流程，不将槽式聚光、风机或光伏组件当作本实验的核心设备。

## 2. 知识目标与能力目标

学习者应了解定日镜双轴跟踪、塔顶集热、熔融盐显热储能、换热和水蒸气朗肯循环等基本原理，识别塔式集热器、定日镜、储热罐、熔盐泵、换热器、给水泵、汽轮机、发电机、凝汽器及吸收式制冷机组的工程作用。操作层面能够完成设备选型、三维布置、二维介质端口连接及运行参数配置；结果层面能够结合DCS监测数据、仿真曲线和评价信息分析方案完整性与运行表现。

## 3. 实验任务与能量转换主线

实验通常按照设备认知、场景搭建、自由搭建、仿真运行、理论考核和结果评价依次组织。对塔式系统而言，核心能量链为太阳辐射能经聚光吸热变成热能，再经蒸汽动力循环转化为机械能和电能；在热能利用支路中，部分热量可进入供暖或吸收式制冷环节。学生既需要认清设备空间位置，也需要辨别熔融盐、水、蒸汽和电气接口对应的不同系统边界，不能仅凭图标相邻就认为设备已经完成有效连接。

# 二、核心设备与工艺流程

## 1. 定日镜与双轴跟踪装置

定日镜是塔式光热系统的主要聚光设备，通过反射镜面将太阳直射光反射至塔顶接收区域。为维持较好的反射方向，典型定日镜需要按照太阳方位和高度变化进行双轴跟踪。其主要结构包括反射镜、支撑机构、驱动机构和跟踪控制部分。定日镜负责反射聚光，不承担将光直接转化成电能的作用；仿真中观察镜面、塔顶吸热器之间的相对位置，有助于理解光学集热效率与遮挡、反射方向及有效受光条件的关系。

## 2. 塔式太阳能集热器与吸热过程

塔式太阳能集热器设置在高塔顶部或相应高位接收区域，接收定日镜场汇聚的太阳辐射并将其转化为工作介质的热能。与光伏电池直接产生直流电不同，光热集热首先形成高温热源，再通过后续换热与动力循环发电。学习时应区分外部受光区域、内部传热通道及高温介质连接位置，了解集热量同时受太阳直射法向辐照度、光学效率、受热面积和热损失影响。三维观察可用于辨识设备构造，具体高温边界应以软件工况和设备说明为准。

## 3. 熔融盐储热罐与显热储能

熔融盐储热通常利用盐的比热容及允许的温度变化实现显热储存。储热罐承担热量暂存与调节的功能，可降低太阳辐射波动对后续用热环节的直接影响。理解储热量时可采用近似关系Q≈m·cp·ΔT，其中m为储热介质质量，cp为定压比热容，ΔT为温度变化；实际可用储热量还受最低工作温度、热损失、流量和系统约束影响。认知储热罐时，应注意区分储能介质、供热需求和发电所需蒸汽三者，不应将熔融盐直接误认为汽轮机的做功蒸汽。

## 4. 熔盐泵与熔盐输送回路

熔盐泵为高温熔融盐在吸热、储热和换热等设备间循环提供流动动力。输送过程需满足回路连通、介质类型及流向要求，泵提供压升而不是额外创造热能。实际工况中，流量影响单位时间能够转移的热量；同一热负荷下，流量与进出口温差具有相互联系。实验时应根据设备端口和工艺方向形成熔盐回路，检查泵与储热罐、集热器和换热设备之间的连接是否合理。泵的扬程、流量和效率等具体输入及取值范围应以软件实际可编辑参数为依据。

## 5. 换热器与蒸汽发生设备

换热设备通过传热壁面把高温熔融盐携带的热量传递给水或其他工作介质，两侧通常保持工质隔离。蒸汽发生设备在获得足够热输入后，使给水经历加热和汽化，形成用于驱动汽轮机的蒸汽。学生需要认识高温热源侧与水汽侧的不同端口，理解换热量受温差、流量、换热面积及传热性能影响。自由搭建时，高温熔盐接口不能随意接到蒸汽出口，介质不匹配或流向错误会导致拓扑不符合工艺要求。设备具体组合应依据原软件已配置的模型组织。

## 6. 汽轮机与发电机

汽轮机利用高温高压蒸汽膨胀做功，使蒸汽的部分热能转化为旋转机械功；发电机再把机械功转化为电能。两者功能不同但在发电环节相互耦合，汽轮机输出受蒸汽入口状态、出口压力、流量和效率等条件影响。学习时要辨认蒸汽进口、排汽出口及机械或电气输出关系，不能把汽轮机视为直接将太阳光变成电能的设备。仿真观察中可关注蒸汽运行状态、发电输出与相关效率指标的变化趋势，具体数值以软件计算和显示为准。

## 7. 凝汽器与给水泵

凝汽器使汽轮机排出的低压蒸汽释放热量并凝结成水，给水泵则将凝结水或给水提升压力并送回后续换热、蒸汽发生环节。二者共同支撑水蒸气动力循环的连续运行。朗肯循环通常包含泵升压、锅炉或蒸汽发生器吸热、汽轮机膨胀做功及凝汽器放热等基本过程。识别相关设备时，应沿水和蒸汽的变化路径查找连接，不要把凝汽器理解为储热罐，也不要混淆给水泵与负责熔融盐输送的熔盐泵。

## 8. 供热系统与热能利用

塔式光热系统除发电外，还可在已有方案中保留热能用于供暖的利用环节。供热支路通常借助换热设备，把可利用的热量传递至供热介质或用户侧，而不要求把高温发电介质直接输送到建筑端。教学应关注热源侧、供热侧和回水侧之间的联系，认识热负荷变化、供回水温差和流量对热量利用的影响。供热设备是塔式系统的辅助热利用内容，不应将其误解为另一种聚光发电方式；相关连接和参数应以实际软件设备库为准。

## 9. 吸收式制冷与余热利用

吸收式制冷利用热能驱动制冷循环，与依靠电动压缩机做功的蒸气压缩制冷不同。典型吸收式机组涉及发生、吸收、冷凝和蒸发等过程，所需驱动热源可以来自具备适宜温度条件的热水或蒸汽。塔式实验保留吸收式制冷设备，用于帮助学生认识热能向冷量的转换及能源梯级利用。学习时应关注驱动热源、冷却环节和冷量输出的基本关系；不要在缺少实际设备与控制依据时臆造特定吸收式工质配对、性能系数或阀门控制方式。

# 三、核心原理与参数分析

## 1. 太阳辐射与集热效率

塔式系统主要依赖太阳直射辐射，聚光场能量输入与直射法向辐照度DNI、有效反射面积和光学效率等相关。可以用“入射太阳功率—光学损失—吸热器热损失—可用热量”的路径分析过程。镜面污损、遮挡、跟踪偏差和吸热器散热等因素可能降低实际有效输入，但这些因素是否单独设置为软件可编辑参数，需要依据界面核查。学生应分清热功率和发电功率：前者反映热量传递速率，后者还受到蒸汽循环与发电机效率影响。

## 2. 储热容量与充放热过程

熔融盐的显热储能能力随介质质量、比热容和有效温差变化。储热并不等同于产生额外能量，而是把某一时段输入的热量保留到后续时段使用，过程中存在传热和散热损失。评价储热过程需区分储热罐的温度状态、储热量、充放热流量和热源侧供热能力。光热发电系统引入储热后，可以在一定条件下改善热能供给时间与发电、供热需求时间之间的匹配，但实际调峰能力由设备容量、运行工况和控制策略决定，不应预设无依据的储热时长。

## 3. 水蒸气朗肯循环与发电效率

水蒸气朗肯循环可用四个典型过程理解：给水泵提高液态水压力、蒸汽发生装置输入热量、汽轮机内蒸汽膨胀做功、凝汽器排热形成凝结水。汽轮机产生的机械功扣除给水泵等辅助功耗后，才可能构成净输出。循环热效率通常与热输入、做功输出、蒸汽参数及设备不可逆损失有关。实验分析应优先比较同一拓扑、相同条件下的参数变化和软件输出结果，避免仅根据单个温度数值判断整体效率。

## 4. 介质端口与工艺拓扑

在二维自由搭建中，设备图标的连线应反映真实工艺关系，而不是简单的几何连接。塔式系统涉及熔融盐侧、水侧、蒸汽侧以及发电电气接口等类型，应先确认两个设备端口允许传递的介质或能量，再确定连接方向与回路闭合关系。典型错误包括把不同介质的端口直接相连、遗漏必要辅助设备、接反入口和出口、形成断路或不合理回路。检查时可沿“吸热—储热—换热—汽轮发电—凝结水回流”的顺序逐段核对。

## 5. DCS数据与运行曲线解读

分散控制系统DCS界面主要用于集中观察仿真系统的运行状态和参数。应先识别数据名称、单位和测点对应设备，再根据工况变化理解其物理含义，例如温度、流量、蒸汽状态和输出变化之间可能存在的关联。运行曲线用于判断变量随时间或工况变化的趋势，而不是自动说明因果关系。分析时建议记录调整前的参数配置，只修改一个可控变量后再次运行，对比主要指标和图表走势；具体可见测点、刷新方式和曲线算法须服从软件运行版本。

# 四、虚拟仿真实验操作

## 1. 设备认知与三维模型观察

进入塔式系统设备认知内容后，依次辨认定日镜、塔顶集热器、储热罐、熔盐泵、换热器、汽轮发电机、凝汽器、给水泵及吸收式制冷机组。利用已有模型的旋转、缩放、局部结构观察及原理动画等方式，理解各设备的外形、关键部件和工程作用。观察时应把设备位置放到整体工艺流程中，而不是仅记住名称；区分聚光设备、流体输送设备、传热设备、动力转换设备及终端用能设备，为后续选型和连接做准备。

## 2. 三维集热场设备选型与布置

在三维场景搭建任务中，从设备库选择塔式太阳能集热器和定日镜等主要设备，按场景要求进行拖放与布置。布置时核对吸热器与定日镜的相对位置，形成能够表达反射聚光关系的集热场，避免把定日镜误放成光伏组件或槽式集热单元。完成主要聚光设备后，观察建筑、设备和工艺区域之间的空间关系。场景内具体可放置的镜面数量、位置约束和判定标准由现有软件场景决定，不自行设定额外工程规则。

## 3. 三维储热及蒸汽动力设备布置

在原有三维搭建界面选择储热罐、熔盐泵、换热器、给水泵、汽轮机、发电机和凝汽器等设备，放置在相应工艺区域，并检查设备类型和位置是否符合任务要求。储热设备应与高温熔盐相关区域对应，换热设备联系热源侧和水汽侧，汽轮机、发电机及凝汽器组成动力发电相关部分。布置完成后可通过漫游或局部视角检查设备之间是否存在明显不合理的空间关系；三维空间摆放与二维介质连接属于两个相互联系但不等价的学习环节。

## 4. 三维供热制冷设备布置与参数配置

根据已有场景可提供的供热及吸收式制冷设备，完成相应设备选择与布置，认识热量从光热发电主流程分配到用热支路的路径。对支持参数输入的设备，在软件给定范围内设置运行参数；参数类型和单位均应以实际参数面板显示为准。配置后可使用原有监控界面观察相关运行信息。供暖和制冷主要用于展示热能梯级利用，不应额外添加尚未开发的控制策略、建筑冷负荷预测功能或自动优化模块。

## 5. 二维自由搭建设备选取与画布组态

进入二维自由搭建后，首先明确目标系统包含的核心环节，再从设备库选取塔式集热、熔盐输送、储热、换热、水汽动力及供热制冷相关设备图标。把图标拖放到画布形成有序的工艺拓扑，建议按照能量流向由左至右或自上而下排列，便于检查。设备图标已被放上画布并不意味着系统能够运行，只有设备选取完整、连接类型正确且必要参数适配，才可能获得有意义的仿真反馈。

## 6. 熔盐、水汽及电气接口连接

按照二维设备接口类型连接相应的工艺通道：熔融盐回路连接吸热、储热和换热设备；水与蒸汽回路连接给水、蒸汽发生、汽轮机和凝汽器相关单元；发电环节按可用电气端口建立相应关系。对每条连接逐一检查端口类型、入口出口、流向和连续性，排除遗漏、反接与跨介质直连。需要注意，是否由界面自动阻止错误连接以及错误提示的具体文字属于软件实现细节，不能脱离运行版本预先认定。

## 7. 运行参数设置与仿真启动

在完成拓扑检查后，打开相应设备的参数配置入口，核对参数名称、工程单位和允许范围，并输入实验任务需要的数值。参数设置应保持逻辑一致，例如热源供应、介质输送、换热能力与动力设备工况之间不能相互矛盾。随后通过界面实际提供的仿真控制功能执行计算，观察运行数据和曲线。若无法形成结果，应先检查设备是否缺失、接口是否匹配、必要参数是否填写，而不是直接判断某台设备故障。

## 8. 工况调整与结果比较

为理解工况变化对系统表现的影响，可在保存或记录初始拓扑及关键参数后，对软件允许调整的变量进行单项修改，然后重新仿真并对照主要运行数据。分析时关注集热侧热输入、储热温度或热量、蒸汽动力侧状态及发电输出的联系。只有在其他条件可比时，前后曲线和指标变化才更容易解释。软件若未开放某参数编辑，则应采用已有工况或现成数据开展分析，不应把理论上可变化的量说成系统一定具有手动修改入口。

## 9. 理论考核、操作评价与报告

完成认知和搭建任务后，可使用原有理论考核功能检验设备结构、光热转换、显热储能、朗肯循环及工艺连接等知识的掌握程度，并查看软件已有的答题反馈或解析。操作评价主要依据软件实际记录的搭建、连接、参数及仿真任务结果；实验报告可结合已有运行图表、数据和成绩进行整理。应区分理论成绩和操作成绩，不把知识库中的说明等同于软件实际评分规则，也不预设未经核实的分值或自动判分阈值。

# 五、结果分析与常见问题

## 1. 如何判断塔式系统的搭建是否完整

判断完整性时可从设备齐全性、介质回路连通性、端口类型一致性、参数可执行性以及结果可读取性五个方面逐项检查。先确认定日镜、塔式集热器、熔盐输送与储热、换热、水汽动力及发电所需设备是否符合任务要求，再检查熔盐和水汽回路是否形成有效工艺路线，最后观察仿真是否产生合理运行信息。设备堆叠得越多不代表方案越完善；缺乏必要连接或者错误连通的系统即使外观完整，也无法表达正确的能量转换关系。

## 2. 光热储能与电池储能有什么区别

本实验的主体储能方式是通过熔融盐等热介质储存热量，后续可以再经换热和动力循环发电；电化学电池储能则利用电池内部可逆电化学过程储存和释放电能。两者存储的能量形态、主要设备、损耗路径、关键评价参数均不同。塔式系统的储热容量通常与介质质量和有效温差有关，而电池储能常涉及容量、功率及荷电状态SOC。讨论光热储能时不能直接拿电池SOC代替熔盐储热量，也不能把二者的充放电效率视为相同。

## 3. 发电效率变化应如何解释

当软件显示发电功率或效率变化时，应从热源输入、换热与介质流量、水蒸气状态、汽轮机做功及设备损耗等环节寻找解释。太阳辐射增强不必然带来同等比例的电功率增加，因为各设备存在工作约束和效率损失。比较不同工况时应明确采用的是毛发电量、净输出功率、热效率还是其它指标，避免单位和口径混淆。具体算法、热效率定义及数值精度应由软件计算模型决定；知识库提供的是工程原理与结果判读方法。

## 4. 高温系统操作的学习边界

塔式光热系统涉及高温熔盐、高温高压蒸汽及复杂的设备联锁，真实电站对材料、绝热、泵启停、压力保护和人员安全有严格要求。虚拟仿真实验适合用于理解设备构成、工艺拓扑、参数影响和运行趋势，但不能直接代替现场操作规程或真实设备调试许可。教学过程中出现介质类型不匹配、运行参数不合理或系统无法稳定输出时，应先依据仿真界面检查并修正方案；不把未在软件中体现的安全保护动作描述为已实现功能。
