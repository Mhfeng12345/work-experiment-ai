# 一、PLC 基本结构与工作原理

## 1. 可编程控制器的组成

可编程控制器（PLC）主要由中央处理单元、电源模块、输入接口、输出接口和通信接口组成。中央处理单元包含运算器、控制器、存储器与时钟，是执行控制逻辑的核心；输入接口把现场开关量、模拟量等信号转换为控制器可识别的数字量；输出接口把运算结果转换为驱动现场设备的控制信号；电源模块为各部分提供稳定的直流电源；通信接口用于连接编程器、上位机、其他 PLC 或现场设备。各部分在箱体或机架上按一定顺序排列，输入与输出端子通常集中布置，便于接线与维护。

## 2. PLC 的工作过程与扫描周期

PLC 采用循环扫描方式工作，一个扫描周期通常包括输入采样、程序执行和输出刷新三个阶段。输入采样阶段以扫描方式读取全部输入端子的状态并存入输入映像区；程序执行阶段按编程顺序逐条执行用户程序，运算结果写入输出映像区；输出刷新阶段把输出映像区的内容集中送到输出端子。扫描周期由输入采样时间、用户程序执行时间、输出刷新时间和通信处理时间组成。扫描周期越短，PLC 响应的实时性越好。在程序执行过程中，输出映像区的内容不会因为程序执行而改变，因此同一扫描周期内后续指令读取的是本周期开始时的输出状态。

## 3. 主要性能指标

衡量 PLC 性能的主要指标包括输入输出点数、用户程序存储容量、指令集范围、扫描速度、通信能力和可靠性。其中输入输出点数指可接入的输入通道与输出通道总数，分为数字量与模拟量，需按工程实际需求选择并留有余量；扫描速度通常以执行一千条基本指令所需时间表示；存储容量决定可容纳程序与数据量的规模。此外还需关注工作环境温度、抗干扰能力、隔离方式和防护等级，以适应现场条件。

# 二、编程语言与存储器

## 1. 常用编程语言

PLC 常见编程语言包括梯形图、指令表、功能块图、结构化文本和顺序功能图。梯形图以继电器控制电路的形式组织程序，逻辑关系直观，适合复杂顺序与互锁逻辑，是使用最广泛的形式；指令表以助记符形式逐条表示操作，与底层指令一一对应，执行效率较高但可读性较差；功能块图以功能块形式组织运算，适合数据运算与模拟量处理；结构化文本采用高级语言风格，便于描述复杂算法与数据处理；顺序功能图以步和转换条件描述控制过程，适合多工序顺序控制。实际工程常以梯形图为主，配合功能块图处理模拟量和数据运算。

## 2. 存储器区域与地址表示

PLC 内部按用途划分为若干存储区，常用区域包括输入过程映像区、输出过程映像区、位存储器区、定时器区、计数器区和数据块区。地址一般由区域标识符和地址编号组成，例如输入区采用 I、输出区采用 Q、位存储器区采用 M、定时器区采用 T、计数器区采用 C、数据块区采用 DB。位地址常写为区域标识符加字节号加点号加点号后位号的形式，如 I0.0、M10.2；字节、字或双字地址以区域标识符加类型标识和地址号表示，其中 B 表示字节、W 表示字、D 表示双字。定时器和计数器通常既有点状态引用，也有字数值引用，引用时必须区分。

## 3. 数据类型与寻址方式

PLC 中常见的数据类型包括位、字节、字和双字等，不同类型占用不同的存储长度，寻址时必须与变量类型匹配，否则会出现读写错误。寻址方式分为直接寻址和间接寻址。直接寻址在指令中给出固定的存储地址，地址不随运行过程变化；间接寻址先从指针单元中取出地址，再以该地址访问目标数据，地址可以在程序运行中改变，适用于数据表处理和循环访问同一组寄存器。编写程序时应确认操作数的数据类型与地址格式一致，例如将双字变量作为字处理会读取到错误结果。

# 三、位运算与逻辑控制

## 1. 基本逻辑元件与逻辑表达式

程序设计中使用的基本逻辑元件包括常开触点、常闭触点和输出线圈。常开触点在其控制信号为逻辑 1 时导通，常闭触点在其控制信号为逻辑 0 时导通，输出线圈在其控制条件成立时得电。多个触点的串联对应逻辑与，并联对应逻辑或，触点或线圈的取反对应逻辑非。任一复杂逻辑控制都可以等效转换为逻辑表达式进行校验，这是检查梯形图是否正确的重要方法之一。

## 2. 边沿检测与状态保持

边沿检测用于识别信号的上升沿或下降沿，一次性动作一个脉冲宽度，常用于计数器输入、单次触发和防止重复响应。状态保持指令用于使输出置位后保持，或复位后释放，常用于启动、停止、报警确认等需要记忆的场景。采用状态保持时，必须明确置位和复位的先后顺序与条件优先级，否则会出现置位后立即被复位或输出无法关闭的问题。此外还需确认扫描周期内重复置位对执行机构的影响，必要时采用上升沿触发避免重复动作。

## 3. 互锁与安全顺序设计

互锁用于保证两个或多个输出不会同时动作，常见于电机正反转、液压缸伸缩等场合。实现互锁时应采用电气互锁与程序互锁双重措施，程序互锁通过常闭触点串入对方线圈回路实现。顺序控制的本质是条件互锁与步骤约束，应明确每个动作的前置条件和后续允许条件。若互锁条件设置不当，可能出现输出同时导通、动作冲突或程序进入不确定状态，因此互锁逻辑在投运前应逐条验证。

# 四、定时器与计数器

## 1. 定时器的工作原理与类型

定时器在输入信号接通并持续达到设定时间后输出动作信号。常用类型包括通电延时定时器，其输入接通时开始计时，到达设定时间后输出接点动作，输入断开时立即复位；断电延时定时器在输入断开后开始计时，到达设定时间后输出复位；脉冲定时器输出一个固定宽度的脉冲。不同类型对应不同的控制需求，选择时应根据信号持续时间和工艺要求确定。设定值应大于设备实际动作时间，避免因参数过紧导致误动作，同时应考虑扫描周期对计时精度的影响。

## 2. 计数器的类型与使用

计数器用于对输入脉冲或事件次数进行累积计数，常见类型包括增计数器、减计数和增减计数器。计数器的当前值和设定值均为数值型数据，需要参与比较时必须使用数值型访问方式。单个计数器对输入信号的频率有上限要求，输入脉冲周期不得小于一个扫描周期，否则可能漏计，因此高速计数通常使用高速计数器指令。累计计数场景还应考虑上电后当前值是否需要清零，以及掉电保持功能是否满足工艺要求。

## 3. 时序控制的组织方法

较复杂的时序控制可采用步序方式组织，把整个过程划分为若干步，每一步设置进入条件、输出动作和转移条件，程序结构清晰且易于排查。时序设计中应注意步与步之间的切换条件必须互斥，避免两个条件同时满足造成跳转不确定；应设置合理的初始步和故障步，保证任何异常情况下程序都能进入可识别的确定状态；对可能长期等待的环节应设置超时监控，避免流程卡死而无提示。调试时应按步逐个验证动作与转移，避免一次性通电检查全部逻辑。

# 五、模拟量与数据处理

## 1. 模拟量输入与输出通道

模拟量输入通道把连续变化的现场信号转换为数字量供程序使用，常见信号类型包括 0 至 10 伏电压信号和 4 至 20 毫安电流信号。电流信号抗干扰能力较强且便于远距离传输，在工业现场应用较多。通道具有分辨率和量程两个关键参数，分辨率决定可分辨的最小变化量，量程决定可测范围。选用时需确认传感器输出范围与通道量程匹配，否则会超出有效测量区间。

## 2. 原始值与工程量之间的换算

模拟量通道读取到的是原始整数，需要按通道增益和偏移换算为工程值。换算应依据模块提供的量程与分辨率参数，按线性关系进行比例运算，并在程序中注明单位。信号类型切换时应确认是否需要在程序中乘以对应系数，例如电流信号零点对应 4 毫安而非 0。做限幅与超量程判断是必要的保护措施，超出量程的数据不能直接参与后续运算，应作为异常处理。

## 3. 工程量的标定与滤波

工程量的标定是将传感器实际测量范围映射到工艺允许范围内，便于操作人员直接读懂显示值与设定值。滤波用于抑制测量噪声，常采用滑动平均、一阶惯性滤波或限幅滤波方法。滤波可以降低显示跳变，但同时会引入响应滞后，参数选择需要在稳定性和快速性之间折中。对温度等变化缓慢的信号可采用较强滤波，对压力流量等变化较快的信号应减小滤波强度。设置报警上下限时，应结合滤波滞后避免误报警。

# 六、通信与人机接口

## 1. PLC 常见通信方式

PLC 之间以及 PLC 与上位设备之间常通过现场总线或工业以太网进行通信，常见方式包括 PROFIBUS、PROFINET、Modbus RTU 与 Modbus TCP、EtherNet/IP 等。Modbus RTU 通过物理层串行链路传输，协议结构简单，常用于电表与变频器等设备；Modbus TCP 在以太网基础上实现，应用范围更广。配置通信参数时必须保证设备地址、通信速率、数据位停止位和校验方式一致，否则会出现读取异常或超时。

## 2. 人机界面与数据显示

人机界面用于显示设备运行状态、参数设定和报警信息，并提供操作控制入口。画面设计应直观反映工艺流程，按功能分区显示实时值、设定值和状态指示，颜色区分正常、警告和故障状态。报警界面应能查看报警发生时间、内容和确认状态。触摸屏或上位机与 PLC 之间的数据交换依赖变量映射，映射关系应形成文档并保持稳定，否则后续维护和故障排查会很困难。

## 3. 数据记录与报表

实验和工程中常需要把运行数据保存为记录，用于分析、追溯和生成报表。常见实现方式是把关键变量周期性写入数据块或日志区，再由上位机读取整理。数据记录应明确采样周期、存储容量和数据格式，并考虑存储空间耗尽后的处理策略。存储容量不足时可能覆盖旧记录或引发写入异常，因此需要设置容量监控。对生成的实验报告，应同时记录采样条件、操作过程和异常情况，保证结果可追溯。

# 七、故障诊断与安全操作

## 1. 常见故障类型

常见故障可分为输入故障、输出故障、CPU 故障、电源故障、通信故障和程序故障。输入故障表现为某个输入点始终不动作或信号失真，常因接线松动、端子损坏或线路短路断路引起；输出故障表现为输出不动作或输出异常，常见原因包括负载过流、继电器损坏或短路；CPU 与电源故障可能导致整机停止运行或无法启动；通信故障表现为与编程器或上位机无法连接。排查时应结合故障指示灯和状态信息逐步缩小范围。

## 2. 诊断方法与常用工具

诊断可采用指示灯观察、状态字读取和交叉诊断方法。指示灯能反映模块运行状态与通信状态；状态字提供扫描周期、诊断信息等运行参数，可用于判断程序是否正常执行；交叉诊断通过比较输入映像区、输出映像区与程序期望值，定位逻辑偏差位置。常用工具包括编程软件的诊断功能和在线监控功能。处理故障时应先记录现象再操作，避免反复通断电扩大损坏。

## 3. 安全操作规范

实验和现场操作必须遵守安全规范。接线、改线和检修前必须断开电源并执行规定的安全确认流程，采取防止意外送电的措施。急停回路应确保可靠动作，急停按钮通常采用直接切断接触器线圈的硬接线方式，不依赖程序逻辑。设备应可靠接地，控制柜应采取防尘、防水和防机械损伤措施，现场应设置必要的防护与警示标识。未经培训和授权不得操作设备，发生异常应立即停机并报告。

# 八、虚拟仿真实验流程

## 1. 实验准备与操作步骤

实验开始前应阅读实验指导书，了解实验目的、所需设备、软件环境和注意事项。准备工作包括检查接线是否正确、供电是否正常、仿真软件或虚拟仿真平台能否正常打开。随后按步骤进行仿真建模或程序编写、参数设置与调试运行。操作过程中应严格按照规定顺序进行，避免跳过必要的确认环节。实验结束后按规定保存程序和工程文件，关闭电源并整理实验台。

## 2. 数据采集与记录要求

实验数据是分析和生成报告的依据，采集时应明确变量名称、单位、采样时刻和采集条件。记录应包含控制参数、运行状态、现象描述和异常情况，不能只记录理想结果。对多次重复的实验应记录多次数据并说明差异来源。采集到的数据应及时保存，避免因软件异常丢失。填写的实验报告应与实际操作一致，不得事后凭记忆编造数据。

## 3. 常见问题的排查思路

实验中遇到输出不动作时应先检查输入信号是否正常，再检查程序中对应逻辑条件是否成立，最后检查输出侧接线与负载；程序不能运行时应检查是否存在语法错误、地址越界或硬件配置不匹配；仿真结果与预期不符时，应先确认参数与实际接线是否一致，再逐步简化程序定位问题。排查过程应记录已验证的环节，避免重复检查。涉及设备安全的调整必须在断电并执行安全确认流程后进行。
