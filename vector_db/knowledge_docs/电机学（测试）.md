# 一、磁路与电磁感应基础

## 1. 磁通、磁感应强度与磁场强度

磁通表示穿过给定截面的磁场总量，单位为韦伯（Wb）；磁感应强度描述磁场的局部强弱，单位为特斯拉（T）；磁场强度用于描述产生磁场的励磁作用，单位为安培每米（A/m）。在均匀磁场且磁场方向与截面法线一致时，磁通可由磁感应强度与截面积的乘积估算。实际电机磁路通常包含铁心、气隙和漏磁路径，因此分析时需要明确采用的简化假设。

## 2. 电磁感应定律在电机中的应用

当线圈所链接的磁通随时间变化时，线圈中会产生感应电动势，其大小与磁通变化率有关。旋转电机通过导体与磁场之间的相对运动实现机电能量转换。发电机运行时，机械输入通过电磁感应转化为电能；电动机运行时，电能建立电磁场并产生电磁转矩，驱动机械负载。

## 3. 铁心损耗的组成

电机铁心损耗通常包括磁滞损耗和涡流损耗。磁滞损耗与铁磁材料反复磁化过程中的能量损失有关；涡流损耗由交变磁通在导电铁心中感生电流而产生。采用叠片铁心并使各片之间保持绝缘，可限制涡流回路，从而降低涡流损耗。铁心材料、磁通密度和工作频率都会影响损耗水平。

# 二、变压器工作原理与运行

## 1. 变压器的基本工作原理

变压器利用交变磁通在两个或多个绕组之间传递电能。原边绕组接入交流电源后产生交变磁通，该磁通与副边绕组交链并感应电动势。在理想变压器近似条件下，电压比约等于匝数比，电流比与匝数比成反比。实际变压器还存在绕组电阻、漏磁通和铁心损耗，因此输出电压会随负载变化。

## 2. 变压器空载与负载运行的区别

空载运行时，副边开路，原边电流主要用于建立主磁通并补偿铁心损耗。负载运行时，副边向负载提供电流，原边电流随之变化，以满足能量平衡。比较空载与负载数据时，应保持电源频率和原边电压等条件一致，并记录副边电压、电流和输入功率。

## 3. 变压器效率的计算与解释

变压器效率定义为输出有功功率与输入有功功率之比。若已测得输入和输出有功功率，可按效率等于输出功率除以输入功率再乘以百分之百计算。效率测试应关注仪表接线、功率因数和负载条件。输入输出功率差可用于估计总损耗，但需考虑测量误差以及测试仪器的精度。

# 三、直流电机特性

## 1. 直流电机的电磁转矩

直流电机电枢导体通电后在磁场中受到电磁力，多个导体产生的合成效果形成电磁转矩。对常见直流电机，在磁通近似不变时，电磁转矩与电枢电流近似成正比。实验中可以改变负载并测量电枢电流和转速，观察转矩变化与电流变化之间的关系。

## 2. 直流电动机的反电动势

直流电动机旋转时，电枢导体切割磁场会产生与电源电压方向相反的感应电动势，称为反电动势。稳态时，电源电压大致用于平衡反电动势和电枢回路电阻压降。启动瞬间转速较低，反电动势较小，因此启动电流可能较大，通常需要采用适当的启动措施限制电流。

## 3. 直流电机调速方式

直流电机常见调速方式包括调节电枢电压、调节励磁磁通以及在允许范围内改变电枢回路参数。不同方式对调速范围、效率和机械特性有不同影响。实验比较调速结果时，应记录负载、励磁条件、电枢电压和转速，避免将负载变化导致的转速变化误认为调速效果。

# 四、三相异步电动机

## 1. 三相旋转磁场的形成

三相定子绕组在空间上相隔一定电角度，通入相位互差的三相交流电后，会产生旋转磁场。旋转磁场的同步转速与电源频率和电机极数有关。三相电源的相序会影响旋转磁场的方向，因此调换任意两相电源线通常会改变电动机的旋转方向。

## 2. 同步转速与转差率

同步转速是定子旋转磁场的转速，常用公式为 n_s = 120f/P，其中 f 为电源频率，P 为磁极数。异步电动机转子转速通常低于同步转速，两者之间的相对差值用转差率表示。转差率可按 s = (n_s - n)/n_s 计算，其中 n 为转子机械转速。计算时应统一转速单位并确认极数定义。

## 3. 异步电动机启动电流偏大的原因

启动时转子尚未达到正常转速，电机的等效运行状态使其从电源吸收较大的电流。较大的启动电流可能引起电源电压暂降和绕组发热。常见启动方式包括直接启动、星三角启动和软启动等，具体选择需考虑电机容量、电网条件、负载转矩和设备要求。启动操作前应确认接线、保护装置和机械负载状态。

## 4. 电动机转向异常的排查

发现电动机转向与预期不符时，应先停止设备并执行规定的断电和安全确认流程，再检查相序、接线图和控制指令。三相异步电动机的旋转方向通常与相序相关，但具体设备还可能受传动机构和控制逻辑影响。排查过程中应记录原始接线状态，未经授权不得带电更改接线。

# 五、电机实验测量与故障诊断

## 1. 转速与转矩测量注意事项

测量转速时应确认传感器安装牢固、量程适合且读数稳定；测量转矩时应确认传感器零点、联轴器状态和加载装置工作正常。记录数据时应注明单位、采样时间和负载条件。若数据波动较大，应检查机械振动、传感器安装、接线和采样设置，再判断是否属于电机本身的运行特性。

## 2. 电机温升异常的常见原因

电机温升异常可能与过载、通风不畅、电源电压不平衡、频繁启动、轴承状态不良或绕组故障有关。诊断时应结合电流、负载、环境温度、冷却条件和运行时间综合判断。单次温度读数不足以确认故障原因，应按设备规程进行复测和检查。

## 3. 实验数据分析与结论记录

电机实验报告应记录电机型号、额定参数、接线方式、仪表量程、负载条件和原始测量数据。分析时应先检查单位和数据完整性，再计算转速、转差率、功率或效率等指标。结论应明确哪些现象由测量数据直接支持，哪些原因仍需进一步验证，不应仅凭一组异常读数就确定故障根因。
