# 一、实验目的

## 1. 平台定位与总体目标

本平台是一套工业电器控制技术实验虚拟仿真软件，以虚实融合的方式复刻真实工业控制场景，供高等院校、职业院校的电气自动化、机电一体化等专业开展 PLC 编程、电气接线、系统调试与故障排查类实验。平台将传统实体实训中成本高、风险大、场景少的环节搬到虚拟环境中，让学生在零触电、零设备损坏的前提下反复练习完整的工控操作流程。总体目标是衔接课堂理论教学、技能实操训练与企业岗位需求，使学生在虚拟环境中掌握的接线、编程、调试技能能够直接迁移到真实设备上，解决实体实训设备不足、更新慢、安全隐患大的问题。使用平台时，学生应按照“实验认知—实验选择—PLC通讯—实验接线—PLC编程—实验现象”六个步骤依次完成，养成规范、完整的工程操作习惯。

## 2. PLC控制核心知识目标

通过本平台的系列实验，学生应理解可编程逻辑控制器（PLC）的基本构成与工作机制。PLC 是专为工业场景设计的自动化控制器，硬件由 CPU、存储器、I/O 模块和电源模块组成，软件由系统程序和用户程序（常用梯形图等语言编写）组成。其核心是毫秒级的循环扫描机制：先一次性采样全部输入信号存入输入映像寄存器，再按顺序执行用户程序进行逻辑运算，最后把结果一次性刷新到输出模块驱动设备。学生需要掌握 PLC 基本位逻辑指令、定时器、计数器、自锁与互锁、顺序控制等常用编程方法，理解 I/O 地址分配、变量定义与硬件接线之间的对应关系，能够根据控制要求独立编写梯形图程序并下载到仿真 PLC 中运行。

## 3. 实践能力培养目标

平台侧重培养学生四项实践能力：一是电气识图与接线能力，能够对照接线图完成主回路与控制回路的端子连接，并通过自检发现错接、漏接；二是编程调试能力，能够在西门子 TIA 博途环境中完成硬件组态、变量定义、程序编写、在线监控与反复优化；三是系统验证能力，能够通过操作现场按钮、观察设备动作与 I/O 点位状态，判断控制逻辑是否正确并排查故障；四是工程思维能力，从单一设备控制逐步过渡到多设备联动、顺序流程与产线级逻辑，理解输入、控制、输出之间的闭环关系。平台同时支持教师进行过程化考核与实验报告管理，学生应认真对待每一次接线检查、程序调试与结果记录。

# 二、实验设备认知

## 1. 西门子S7-1200 PLC

西门子 S7-1200 是平台采用的仿真控制器，属于紧凑型中小型 PLC，是当前工业现场应用广泛的型号，功能全面、性价比高，适合教学与中小型项目。它具备逻辑控制、模拟量处理、运动控制与通信联网等能力，集成 PROFINET 接口，可与上位机通信。平台完整仿真了其指令体系与循环扫描工作机制，学生在 TIA 博途中编写的梯形图程序逻辑与真实 S7-1200 完全一致，技能可直接迁移。实验中需要先在博途里添加与仿真型号一致的 PLC，完成硬件组态，设置与仿真平台相同的 IP 地址、机架号和槽号，定义好与 I/O 分配表一致的变量地址，再将项目转在线、下载程序并使 PLC 进入运行状态。

## 2. PLC控制柜

PLC 控制柜是控制系统的中枢柜体，内部集成 PLC 主机、电源模块、继电器、端子排、断路器等电气元件，所有控制信号在此汇集处理。平台提供可虚拟实操的 PLC 控制柜，学生可以在柜内完成端子接线、程序下载与在线监控，完全复刻真实控制柜的操作体验。接线时需区分主回路与控制回路，按接线图逐一对应端子，避免错接、虚接和漏接；鼠标悬停在端子附近会出现红色标识并显示端子名称，便于精准定位。完成接线后点击“提交检查”，系统会自动判定接线正确性并标注错误位置，学生应根据提示修正后重新检查，直至通过再进入编程环节。

## 3. G120变频器

西门子 G120 变频器是通用型低压变频调速设备，由功率模块与控制单元组成，通过改变输出电源频率调节三相电机转速，广泛用于传送带、风机、泵类、主轴等设备的调速与节能控制。在平台的“G120变频器PLC线控及正反转控制”实验中，PLC 通过端子输出信号控制变频器实现电机正转、反转、停止，并可扩展多段速调速。操作要点是先完成 PLC、变频器、电机之间的电气接线，再正确设置变频器参数（控制方式、频率给定方式、电机参数等），然后由 PLC 编写正反转逻辑，注意正反转之间必须设置互锁防止短路，最后下载程序验证调速与转向效果。

## 4. 三相发电机（三相异步电机）

平台中的三相发电机（三相异步电机）是主要的动力执行设备，通过电磁感应将电能转换为机械能，驱动机床、传送带、提升机构等运转。学生可在实验中观察其直接启动、正反转、星三角启动与变频调速等不同运行状态：直接启动电流冲击大；星三角启动先以星形连接降压启动、再切换三角形全压运行以降低启动电流；变频调速则平滑加减速。电机类实验（电机正反转、星三角启动、变频器控制）是学习 PLC 位逻辑指令与接触器互锁的入门载体，学生要理解自锁保持、正反转互锁、启停按钮的逻辑关系，通过在线监控输入输出点位判断动作是否符合预期。

## 5. 继电器

继电器是一种用小功率信号控制大功率负载的自动开关，在自动化回路中承担信号放大、电路隔离、多点控制与自动切换的作用。平台中的继电器包括中间继电器、时间继电器等，安装于 PLC 控制柜内，用于放大 PLC 输出、驱动接触器或其他大功率元件，并将控制回路与主回路电气隔离以保障安全。学习时应理解继电器线圈得电、触点吸合与复位的过程，明确常开（NO）、常闭（NC）触点在逻辑中的作用，以及电气互锁如何通过常闭触点实现。接线实验中要按图正确连接线圈端与触点端，避免把互锁触点接反导致短路风险。

## 6. 交通灯单元

交通灯单元是时序控制的经典实验对象，包含红、黄、绿三组信号灯，按固定时序循环切换。在“十字路口交通灯”实验中，东西方向与南北方向信号灯交替点亮：某方向绿灯亮一段时间、结束前黄灯闪烁提醒变灯，随后切换为红灯，另一方向转为绿灯，周而复始。该实验主要训练定时器的使用与时序逻辑设计，学生需要把每个灯的点亮时长、先后顺序转化为定时器触发条件，合理分配各灯的输出地址。学习重点是理解时间序列的编排、绿灯到黄灯的过渡提示，以及两个方向信号灯不能同时放行的互斥关系。

## 7. 水塔（水位控制装置）

水塔水位装置是过程控制类实验对象，由液位传感器、水泵电机和蓄水塔组成，通过检测水位高低自动控制水泵启停，使水位保持在设定区间。在“水塔水位控制”实验中，当液位低于下限时启动水泵注水，上升到上限时停止水泵，既防止缺水也防止溢出。该实验训练学生对液位信号（开关量或模拟量）的采集与阈值判断，理解带滞回的水位控制逻辑，避免水泵在临界水位频繁启停。学生需要正确接入液位传感器信号与水泵控制回路，在程序中设置上下限比较与自锁，运行后观察水位升降与水泵动作是否平稳合理。

## 8. 数码管

数码管是由发光二极管段组成的数字显示器件，平台用于数字与状态显示实验。通过 PLC 输出控制不同发光段的亮灭，可组合显示 0 至 9 等数字与字符；数码管分共阳极与共阴极两种，驱动电平相反。“数码管控制”实验训练学生的段选编码与输出映射能力，理解多位数码管动态扫描的基本思路，并可与计数器实验结合实时显示计数值。学习时要掌握各数字对应的段码、输出地址分配，以及段点亮与数字之间的对应关系，为后续复杂显示与计数系统打基础。

## 9. 组合机床

组合机床是离散制造中的典型加工设备，以通用部件为基础，配装按工件要求设计的专用主轴箱、夹具等，用于大批量、高效率的钻孔、攻丝、铣削等加工。“组合机床的电气控制系统”实验还原了工件夹紧、刀具快进、工进切削、快退、松开等自动加工工序，工序之间顺序严格、不可颠倒，是顺序控制的典型案例。学生需要采用顺序控制思想，利用位置开关、压力（夹紧）信号作为工序触发条件，设计每道工序的启动与完成判据，保证工件未夹紧不进给、加工到位才退回。实验重点是多工序联锁与顺序步的转换逻辑。

## 10. 电梯模型

电梯模型是复杂时序与调度逻辑的综合实验对象，包含轿内选层、厅外呼梯、开关门、楼层显示、运行方向指示等功能。“电梯控制”实验逻辑较复杂，需要响应多个呼梯请求、判断运行方向、实现同向优先与反向等待，到达楼层后自动开门、延时关门。学生要综合运用定时器（开关门延时）、计数器或比较指令（楼层判断）、自锁与互锁（上行/下行、开门/关门），建立对多输入、多输出协调逻辑的整体认识。该实验用于锻炼复杂逻辑的分析与分步设计能力，建议先画出楼层与请求的状态流程，再逐段编写程序并在线调试。

## 11. 流水灯

流水灯是入门级时序与移位控制实验对象，由一组 LED 灯按预定顺序依次亮灭形成流动效果。“流水灯控制”实验可实现从左到右依次点亮、双向追逐、中间扩散等多种花样，主要训练移位指令、定时器与循环逻辑的使用。作为 PLC 入门实验，它包含输入、输出、定时与循环等基本要素，学生通过它快速熟悉平台操作与梯形图基本写法。学习重点是理解灯状态如何随时间逐位移动、如何用定时器控制流动间隔、如何循环回到起点，为交通灯、喷泉等更复杂时序实验做准备。

## 12. 液体混合器

液体混合器是顺序控制与配比实验对象，由多个进料阀门、液位传感器、搅拌电机和出料阀组成，按设定比例和顺序混合多种液体并搅拌均匀后排出。实验流程一般为：开 A 阀注液到指定液位、关 A 开 B、再到指定液位关 B 开 C，满罐后关阀启动搅拌，定时搅拌结束后开出料阀排空，再进入下一循环。学生需要用液位信号作为阀位切换条件、用定时器控制搅拌时长，设计完整的顺序步逻辑。重点是各阀门互斥（不能同时开多种料）、液位判据准确、搅拌与出料顺序正确。

## 13. 自动洗衣机

自动洗衣机是多工序顺序控制的生活类实验对象，包含进水、洗涤、排水、脱水等阶段。“自动洗衣机控制”实验按流程工作：进水阀注水到设定水位后关闭，电机正反转交替洗涤并计时，到时停止电机排水，排尽后高速脱水，脱水时间到即结束。学生需要综合运用液位判断、电机正反转互锁、多段定时器与顺序步转换，理解生活设备背后的 PLC 控制逻辑。学习重点是各工序之间的条件衔接、洗涤阶段正反转交替的时间配合，以及排水、脱水的先后顺序，是顺序控制能力的综合巩固。

# 三、平台操作流程

## 1. 登录与主界面

双击桌面快捷方式启动软件，进入登录界面，输入由管理员分配的账号与密码后点击登录，进入实验选择主界面。教师账号拥有班级管理、成绩查看等管理权限，学生账号仅可进行实验操作、提交报告与查看个人成绩。主界面以卡片形式展示全部可选实验场景，每张卡片配 3D 预览图与实验名称，点击卡片即可进入对应实验。顶部标题栏提供“提交报告”“退出”等全局按钮；进入具体实验后，界面分为左侧功能操作区（按流程排布实验认知、电器接线、连接PLC、开始编程等按钮）与右侧仿真场景区，场景可用鼠标拖拽旋转、滚轮缩放。

## 2. 实验认知模块

实验认知是进入实操前的理论学习入口，分为实验背景、实验原理、设备认知三个子模块，通过“上一步/下一步”切换。实验背景讲解 PLC 在工业自动化中的作用与虚实融合实训的意义；实验原理讲解 PLC 硬件构成、软件组成与循环扫描三阶段机制；设备认知以 3D 模型展示平台中的各类工控设备，可 360 度查看外观并了解功能与应用。学生应先完成本模块学习，理解实验原理与设备作用后再进行接线与编程，做到知其然也知其所以然。

## 3. 实验选择模块

实验选择模块共提供十五个实验供选择，分别为：G120变频器PLC线控及正反转控制、电机正反转控制、十字路口交通灯、四节传送带控制、音乐喷泉控制、自动配料装车系统控制、数码管控制、水塔水位控制、自动洗衣机控制、流水灯控制、液体混合、温度PID控制、电梯控制、组合机床的电气控制系统、电机的星三角启动。实验按基础入门、专项提升、综合应用由易到难排布，建议先从流水灯、电机正反转、数码管等入门实验熟悉平台，再进入时序与过程控制实验，最后完成传送带、配料装车、组合机床、电梯等综合实验。

## 4. PLC通讯配置

点击功能区“连接PLC”进入通讯配置界面。先选择与实验一致的 PLC 型号（平台支持 S7-1200、S7-1500，基础教学推荐 S7-1200），再配置 IP 地址、机架号（Rack）、槽号（Slot），默认 IP 为 192.168.0.1、机架号 0、槽号 1，这些参数必须与 TIA 博途硬件组态完全一致，否则无法建立连接。界面右侧的 I/O 分配表列出全部输入信号（按钮、传感器等，对应 I 区）与输出信号（电机、指示灯等，对应 Q 区）的名称、类型与地址，学生须在博途变量表中逐一对应，地址错位会导致程序逻辑正确却无法驱动设备。

## 5. 电气接线操作

点击“电器接线”进入接线界面，平台提供正交模式（平面正视、端子整齐、便于精准接线）与透视模式（3D 立体、展示柜体布局与走线）两种视图，可一键切换且接线同步。操作时将鼠标移到端子附近，出现红色标识并显示端子名；点击起始端子再点目标端子即完成一根连线；可切换线颜色区分主回路与控制回路，选中导线可删除重接。点击右侧“接线图”可查看标准接线图对照完成，界面显示接线进度（如 1/31）。完成后点击“提交检查”，系统自动检测接线正确性并标注错误，修正后重新检查，通过后方可进入编程。

## 6. PLC编程与程序下载

完成接线与通讯配置后，在 TIA 博途中新建项目、添加对应 PLC、完成硬件组态（IP、机架、槽号与仿真一致），按 I/O 分配表定义变量，根据控制要求编写梯形图程序。编程可使用梯形图、功能块图、结构化控制语言等，兼容真实 PLC 标准指令。编写完成后将博途项目转至在线模式，搜索并连接虚拟 PLC，把程序下载到 PLC 并使其进入运行状态。编程过程中善用在线监控，观察变量状态，逐段验证逻辑，发现错误及时修改并重新下载。

## 7. 实验现象验证与I/O监控

程序下载并运行后，点击“开始编程”按钮，仿真软件读取 PLC 运行结果，虚拟场景按程序逻辑实时动作。点击场景中的按钮、开关等交互元件触发输入，观察设备运行状态是否符合控制要求（如正反转实验中按正转按钮电机正向运转、按反转按钮反向运转、按停止按钮停机）。右侧 I/O 分配表实时显示各点位状态（布尔量显示 True/False，模拟量显示数值），可据此判断信号是否正常传输，辅助定位是接线问题、地址问题还是程序逻辑问题。应反复调试优化，直至现象完全满足控制要求。

## 8. 提交报告

完成接线、编程、运行验证并确认逻辑正确后，点击右上角“提交报告”，系统自动记录本次接线情况、程序逻辑、运行结果与答题成绩，生成标准化实验报告。报告包含实验基本信息、实验原理、电气接线、PLC 程序、运行结果与现象分析、配套习题成绩等，学生可导出 PDF 打印提交。重新完成实验并再次提交可覆盖前一次报告，以最后一次提交为准。教师可在后台批量查看、批阅班级学生报告并汇总成绩。

# 四、各实验控制要点

## 1. 电机正反转控制

电机正反转是最基础的电机方向控制实验。控制要求：按正转按钮电机正转，按反转按钮电机反转，按停止按钮停机，正反转之间必须互锁防止相间短路。编程核心是两个接触器（输出）的自锁保持与常闭触点互锁，正转回路串入反转常闭触点、反转回路串入正转常闭触点，使两者不能同时得电。接线时按图连接正转、反转、停止按钮与接触器主回路、控制回路，下载程序后分别操作两个按钮，验证转向切换与停止效果，并通过 I/O 表观察输出状态。

## 2. 电机的星三角启动

星三角启动用于降低大功率电机的启动电流冲击。启动阶段电机绕组接成星形（Y），每相绕组承受较低电压，减小启动电流；转速上升后切换为三角形（△）全压正常运行。实验要点是用两个接触器分别实现星形与三角形接法，由定时器控制启动到运行的切换时刻，并保证星形与三角形接触器互锁，切换瞬间做好短暂延时避免短路。学生需理解降压启动的意义，编写启动、定时、切换、停止的顺序逻辑，运行后观察电机启动过程与切换动作。

## 3. G120变频器PLC线控及正反转控制

本实验通过 PLC 端子控制 G120 变频器实现电机正转、反转、停止及多段速调速。先完成 PLC、变频器、电机主回路与控制回路接线，在变频器中设置端子控制模式、频率给定方式与电机铭牌参数，再由 PLC 输出正转、反转、停止信号并设置互锁。多段速实验通过多个数字输入端子的组合选择固定速度。重点是变频器参数与 PLC 端子信号的对应、正反转互锁，以及运行后通过 I/O 状态验证变频器指令是否被正确接收。

## 4. 十字路口交通灯

交通灯实验训练定时器与双方向时序编排。典型要求：东西方向绿灯亮约 25 秒（同时南北红灯亮），绿灯结束前黄灯闪烁 3 秒提醒，随后东西转红灯、南北转绿灯 25 秒，南北黄灯闪烁 3 秒后循环。学生用多个定时器分段计时，把各灯的点亮时段用定时器触点组合出来，并保证两个方向绿灯互斥。学习重点是时间轴的合理划分、黄灯过渡提示与方向互锁，运行后观察灯色切换是否连贯、无冲突。

## 5. 四节传送带控制

四节传送带是多设备联动的产线实验，训练逆序启动、顺序停止与故障保护逻辑。要求：启动时从出料端到进料端逆序依次启动（间隔数秒），避免物料堆积；停止时从进料端到出料端顺序停止，确保物料送空；某段故障时该段及进料端全部停机、出料端继续运行清空物料；光电传感器检测到工件时对应段自动运行。学生需设计各段之间的启动/停止时序与联锁，理解产线节拍与物料流向，运行后模拟送料与故障验证逻辑。

## 6. 流水灯控制

流水灯是入门时序/移位实验，一组 LED 按时间间隔逐位亮灭形成流动效果，可实现单向流水、双向追逐、中间扩散等花样。编程使用移位指令配合定时器控制移动间隔，并用循环回到起点。实验目标是熟悉平台操作、位输出、定时器与循环结构，为交通灯、喷泉等复杂时序实验打基础。运行后观察灯光流动方向、速度与循环是否符合设计。

## 7. 数码管控制

数码管实验训练段选编码与数字显示。按共阳/共阴类型把 0 至 9 对应的段码映射到 PLC 输出，控制各发光段亮灭显示数字，可结合计数器实时显示计数值。重点是段码表与输出地址的对应、多位显示的动态扫描思路。运行后逐位验证显示数字是否正确，检查是否有段常亮或不亮的编码错误。

## 8. 音乐喷泉控制

音乐喷泉是时序与模拟量结合的综合实验，控制多组水柱依次喷出、灯光随水柱变化，并可调节水柱高度形成不同造型。编程涉及复杂时序编排与模拟量输出（调节喷水强度/灯光）。学生需要把喷泉造型分解为有序的开关动作序列，配合定时与模拟量输出，理解时序逻辑与模拟量控制的结合。运行后观察水柱与灯光配合是否符合设计节奏。

## 9. 水塔水位控制

水塔水位实验训练液位采集与阈值判断。液位低于下限时启动水泵注水，达到上限时停止，保持水位在区间内，并加入滞回避免临界频繁启停。接线正确接入液位传感器与水泵回路，程序中做上下限比较与自锁。运行后观察水位升降时水泵启停是否平稳、无频繁抖动。

## 10. 液体混合

液体混合是顺序配比实验：开 A 阀注液到指定液位、关 A 开 B、再到液位关 B 开 C，满罐关阀启动搅拌，定时搅拌后开出料阀排空，进入下一循环。用液位信号切换阀门、定时器控制搅拌时长，各进料阀互斥。重点是阀门顺序、液位判据与搅拌/出料衔接，运行后观察配比与搅拌、排液流程是否正确。

## 11. 温度PID控制

温度 PID 控制是典型过程控制实验，通过温度传感器采集加热罐温度，由 PID 算法调节加热器功率，把温度稳定控制在设定值（如精度 ±1℃）。学生需要理解比例、积分、微分的作用，学习 PID 参数整定方法，完成模拟量输入（温度采集）与模拟量输出（功率调节）编程。运行后观察温度曲线能否平稳趋近设定值、有无明显超调或振荡，反复整定参数改善效果。

## 12. 自动洗衣机控制

自动洗衣机按进水、洗涤、排水、脱水顺序工作：注水到水位关阀，电机正反转交替洗涤计时，到时排水，排尽后高速脱水，时间到结束。综合运用液位判断、电机正反转互锁、多段定时器与顺序步转换。重点是工序条件衔接、洗涤正反转交替配合与排水脱水顺序，运行后观察完整洗衣流程是否顺畅。

## 13. 电梯控制

电梯实验综合了选层、呼梯、开关门、楼层显示与方向调度逻辑。响应轿内选层与厅外呼梯，遵循同向优先、反向等待原则，到站自动开门、延时关门。编程结合定时器（门延时）、楼层比较判断、上行/下行与开门/关门互锁。建议先梳理楼层与请求状态流程再分步编写，运行后验证呼梯响应、方向选择与开关门动作是否合理。

## 14. 组合机床的电气控制系统

组合机床实验训练多工序顺序控制：工件夹紧到位后主轴启动、刀具快进，到位转工进切削，加工到位快退，回原位主轴停、工件松开。用位置开关与夹紧信号作为工序触发与完成判据，保证未夹紧不进给、工序不颠倒。采用顺序步思想编写，运行后验证夹紧、快进、工进、快退、松开的完整动作顺序与联锁。

## 15. 自动配料装车系统控制

自动配料装车是复杂流程与模拟量（称重）综合实验：按启动按钮栏杆落下、进料装置配料，称重传感器实时检测重量、达到设定值停进料，配料完成开卸料门装车，装毕关门栏杆抬起，急停按钮可紧急停止全部动作。重点是称重模拟量采集与到达值判断、顺序流程与急停保护，运行后验证配料、装车、栏杆动作与急停是否可靠。

# 五、常见问题与排查

## 1. 博途无法连接虚拟PLC

若 TIA 博途搜索不到或连接不上虚拟 PLC，先逐项排查：确认博途中 PLC 型号与仿真平台所选型号一致；核对 IP 地址、机架号、槽号是否与通讯配置完全相同；检查电脑防火墙是否阻挡通讯，可暂时关闭防火墙重试；确认硬件组态无误后重新搜索连接。多数连接失败都是型号不符、IP 或槽号不一致、防火墙拦截造成的，按此顺序检查即可定位。

## 2. 接线检查总是不通过

接线提交检查不通过时，对照标准接线图逐一核对端子序号，区分主回路与控制回路，检查是否存在漏接、虚接、端子错接，尤其注意互锁触点、公共端与电源端是否接反。利用悬停显示的端子名定位，根据系统标注的错误位置针对性修正，改完重新提交检查，直至通过再进行编程，避免带错线进入下一环节。

## 3. 下载程序后设备没有反应

程序下载后设备无动作，按由硬到软的顺序排查：先确认 PLC 处于运行状态、通讯连接正常；再检查 I/O 地址是否与分配表一致、变量定义是否错位；然后在线监控程序，看输入按钮触发时对应输入点是否变为 True、程序逻辑是否导通、输出点是否有状态；最后检查输出回路接线。通过 I/O 表状态可以快速区分是接线问题、地址问题还是逻辑问题。

## 4. 软件启动异常

软件启动报错或闪退时，先检查电脑配置是否满足运行要求（建议 Windows 10/11 64 位、四核以上处理器、8GB 以上内存、独立显卡），更新显卡驱动，尝试以管理员身份运行；必要时暂时关闭杀毒软件后重试。仍异常可联系技术支持并提供报错信息。日常使用中应保证 TIA 博途版本与平台要求匹配，避免通讯环境冲突。
