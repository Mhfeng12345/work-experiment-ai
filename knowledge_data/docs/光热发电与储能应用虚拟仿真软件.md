# 一、实验定位与教学目标

## 1. 实验对象与范围

光热发电与储能应用虚拟仿真软件以塔式太阳能光热发电、槽式太阳能光热发电及原有储能应用功能为教学对象，保留两条光热技术路线的设备认知、三维场景搭建与相应运行内容，并结合原有的储热、储冷和储电设备认识不同能量形态的储存与利用。它是对已有功能的组合，而不是另行新建“塔式与槽式综合对比实验”。学生分别学习两类聚光发电系统，再在已有二维自由搭建与评价功能中完成设备选择、连接、参数配置和结果分析。

## 2. 知识目标与技能目标

知识目标包括理解定日镜双轴跟踪与塔顶吸热、槽式聚光器单轴跟踪与集热、换热和蒸汽动力发电、熔融盐显热储能，以及常见热量、电能和冷量储存设备的主要用途。技能目标包括通过三维观察辨认设备结构，在已有场景中选择和布置塔式或槽式设备，在二维自由搭建中连接匹配的介质与电气端口，并借助参数面板、DCS及运行曲线分析系统工况。学习重点是理解系统构成及工程连接，而非背诵未核实的软件参数数值。

## 3. 实验流程与功能边界

教学过程主要由设备认知、三维场景搭建、二维自由搭建、仿真运行、理论考核和实验评价构成。塔式与槽式应分别认识、分别操作其相应设备和运行内容；在储能环节，使用原软件确实已有的储热、储电和储冷设备与功能，不额外声明新建了跨技术路线的联合调度、综合效率排名或一键优化功能。涉及具体按钮、界面布局、评分阈值和计算方程时，以最终拆分整合后的运行版本为准，知识库只陈述有证据的原理与操作逻辑。

# 二、塔式光热发电系统

## 1. 塔式聚光场与定日镜

塔式光热发电采用定日镜场把太阳直射辐射反射至高塔顶部的吸热设备。定日镜通常配置双轴跟踪机构，随太阳方位和高度变化调整反射镜朝向，以维持有效反射聚光。定日镜的主要任务是改变太阳光的传播方向，而不是像光伏板那样直接产生直流电。三维认知时应关注镜面、支架、驱动装置和塔顶吸热部位的空间关系；实验中可以通过模型观察与原理动画理解聚光过程。实际集热效果受太阳辐照、镜场布置、跟踪精度和光学损失影响。

## 2. 塔顶吸热器与熔融盐传热

塔顶吸热器接收定日镜场汇集的太阳辐射，将其转化为工作介质的热量。原有塔式方案使用熔融盐等高温传热或储热介质组织相关热能输送环节。熔盐由泵推动流动，与集热设备、储热罐和换热器建立热量传递关系。吸热器输出的热量取决于入射光学功率、吸收性能及热损失；储热罐能够缓冲部分热量供给变化。学习中应区分反射聚光、介质吸热、热量存储和水汽蒸汽发生等环节，不能将熔融盐直接理解为汽轮机使用的水蒸气。

## 3. 塔式储热及水汽动力发电

高温熔融盐通过储热或换热环节向水汽系统提供热量，使给水升温、汽化并形成可推动汽轮机的蒸汽。汽轮机将蒸汽膨胀过程中的部分热能转化为旋转机械功，发电机再将机械功转换为电能；乏汽经凝汽器冷凝，给水泵推动工质返回循环。塔式系统因而体现了从太阳辐射能、热能、机械能到电能的逐级转化。场景搭建时应把集热、储热、蒸汽发生、汽轮发电及回水环节作为连续工艺理解，关注端口对应的介质和流向。

## 4. 塔式供热和吸收式制冷

塔式光热发电除动力发电外，还保留热能供暖与吸收式制冷相关设备及利用功能。供热环节通常经适当换热设施向用热侧转移能量；吸收式制冷则利用热驱动过程形成冷量，与主要依靠电动压缩机的制冷技术不同。学生在三维场景和已有设备库中辨认这些辅助单元，认识热能的梯级利用思路。应注意供热和制冷是塔式系统的热能利用支路，不能改变定日镜、吸热器、熔盐储热与蒸汽动力发电组成的核心工艺链，也不能推定存在未实现的自动热负荷优化控制。

# 三、槽式光热发电系统

## 1. 槽式聚光器与单轴跟踪

槽式太阳能光热发电使用槽形抛物面反射镜将入射太阳辐射汇聚到焦线附近的吸热部位，聚光结构沿较长的集热器方向布置。典型槽式聚光装置采用单轴跟踪，使反射面随太阳位置变化调整朝向。槽式聚光器与塔式定日镜的核心差别在于反射镜几何形状、焦点或焦线形式、跟踪方式和集热设备布局。观察三维模型时应辨认槽形反射镜、支架、跟踪装置以及沿焦线设置的吸热管或受热部位，理解其聚光并加热介质的原理。

## 2. 槽式吸热与导热介质循环

槽式集热系统将太阳辐射汇聚至吸热管或相应受热部位，使其中流动的传热介质获得热量。被加热的介质继续把热量送往换热、储热或蒸汽发生环节。与塔式集中在高塔顶部吸热不同，槽式集热一般沿集热场的多个槽形单元分布式收集热量。传热回路需要关注工质流量、进出口温差、热损失和输送动力。具体槽式设备在原软件中采用何种传热介质、热工参数及回路组合应依据已有模型与参数界面，不将所有工程示例都当成该软件实际配置。

## 3. 槽式储热及蒸汽动力转换

槽式太阳能光热发电获得的热量可通过换热设备用于储热或提供蒸汽发生所需热源，再由汽轮发电机完成热功转化。原项目保留熔融盐储热和水汽动力发电等已有设备与内容，储热部分用于理解太阳能输入和用热需求之间的时间协调。对于具体储热系统，应分清集热回路与储热回路是否为同一种工作介质，不能默认所有槽式系统均为熔融盐直接流经吸热管。蒸汽发生与汽轮机工作仍需满足热源温度、蒸汽状态及水汽循环的工艺要求。

## 4. 槽式发电与供热制冷单元

槽式光热发电系统保留原有的蒸汽动力发电以及供热、吸收式制冷等热能利用功能。其核心为槽式聚光集热和后续换热发电，热量利用支路可帮助学生认识不同终端能源需求对系统布局的影响。供热可以通过换热网络向用户侧传递热量，吸收式制冷通过热驱动循环提供冷量，两者都不能简单视为发电机的附属电气负荷。实验时将槽式集热场、储热、蒸汽发生、汽轮发电和热利用设备分别归类，有助于正确完成三维搭建及二维接口连接。

# 四、储能设备及系统关联

## 1. 熔融盐与储热罐的热量存储

熔融盐储热利用材料在允许温度范围内的显热变化存储热能，简单估算关系为Q≈m·cp·ΔT。储热罐及相关输送设备将高温热源的供热时间与后续发电、供热需求进行一定程度的解耦。实际可用热量受到介质物性、流量、最低工作温度、散热损失及系统配置约束。塔式和槽式均可学习储热概念，但不同集热技术路线的设备布置和热源条件并不完全相同。软件中若展示储热温度、热流量或运行曲线，应先确认变量意义和单位再分析。

## 2. 储热水箱与板式太阳能集热设备

原有储热资源还包括储热水箱、板式太阳能集热器等热利用设备。板式太阳能集热器吸收太阳辐射并加热循环工质，热水箱则在一定温度范围内储存和调节热水热量；水泵支持循环输送。该类设备与定日镜及槽式聚光装置用途不同，主要用于一般热利用而非形成高温蒸汽动力发电热源。认知储热水箱时，应把储水温度、储水质量和有效温差联系起来，不能仅凭水箱容积判断可供利用的全部热量。是否与其它系统同屏自由组态以现有界面实际功能为准。

## 3. 储电电池与逆变设备

储电装置通过可逆电化学过程吸收和释放电能，储能容量、充放电功率及荷电状态SOC用于描述不同运行特征。逆变器或其它电力电子装置可以完成直流与交流侧的电能转换，便于储能与相应电气系统建立联系。光热发电侧输出电能与电化学储能侧的能量交换涉及电气接口匹配；电池并不能直接替代熔盐储热罐，也不能存储高温工质本身。实验中应把热储能、电储能和发电侧接口分清，避免将储热量、储电量以及瞬时电功率混为一个指标。

## 4. 制冷设备与冷量储存

原有光热储能应用资料保留制冷设备、换热及储冷水箱等相关资源，用于认识冷量生产、传递及储存。吸收式制冷通常使用热驱动过程，螺杆式等蒸气压缩制冷设备通常由电动压缩机驱动，两类设备在主要能源输入与运行机理上不同。储冷水箱则利用冷水等介质储存可供后续利用的冷量，与电池储存电能不同。教学时应区分制冷量、制冷功率、储冷容量和设备能耗；不同设备是否存在具体联动控制或定量算法，应以已经实现的软件运行逻辑为依据。

## 5. 电储能、热储能和冷储能的比较

储能可以根据储存能量的主要形态划分为电储能、热储能和冷储能。电池借助电化学过程存储电能，熔融盐与热水等介质通过温度变化存储热量，储冷水箱等装置可在适宜温度范围内保存可用冷量。三者共同体现能量跨时段利用的目的，但介质、参数、损耗机制和用途各不相同。对比时应先明确能量种类、容量单位、转换路径和实际可用范围，不直接比较不具共同换算口径的数值。知识库介绍原理，不预设软件已建设独立的三种储能性能对比实验。

# 五、软件认知与三维场景实验

## 1. 塔式设备认知与结构观察

在塔式设备认知任务中依次查看定日镜、塔顶集热器、熔融盐储热与输送设备、蒸汽发生与汽轮发电设备。结合已有三维模型提供的旋转、缩放、局部部件展示及原理动画，识别聚光、吸热、储热、换热和发电过程中的各类设备。观察定日镜与吸热器的位置关系，理解双轴跟踪的作用；观察熔盐泵、储热罐和换热器，分清热源侧与水汽侧。完成认知后应能依据设备名称说明其上游输入、下游输出及对应能源形式。

## 2. 塔式三维场景设备选择与布置

在塔式三维场景中，通过已有设备库选择塔式集热器、定日镜、储热罐、熔盐泵及换热设备，按任务场景完成相应布置。随后补充给水泵、汽轮机、发电机、凝汽器及相关供热制冷设备，形成塔式系统的主要空间布局。三维场景布置的重点是设备类型正确、空间位置合适以及工艺顺序易于理解。软件若支持设备参数设置与漫游检查，可以据此核对各个单元；不要把摆放完成直接等同于二维工艺接口已经连接成功。

## 3. 塔式运行参数设置和DCS监控

完成塔式场景主要设备的配置后，根据软件开放的参数面板设置可调运行条件，核对每项输入对应的设备、单位和取值范围。原系统保留DCS运行监控内容，可用于读取塔式场景中的相关运行信息。观察数据时应把太阳辐射、吸热与传热、蒸汽状态及发电输出联系起来，避免孤立解释某个测点变化。对确实开放编辑的变量进行调整后，可在可比的条件下比较前后结果；对只读指标不应声称具有直接手动编辑能力。

## 4. 槽式设备认知与单轴跟踪观察

在槽式设备认知内容中，重点识别槽形聚光反射镜、焦线附近的吸热部件、跟踪装置及相关换热、储热和动力发电设备。利用模型观察和原理动画了解槽式聚光与传热过程，并与塔式的定日镜双轴跟踪和塔顶集中吸热加以区分。槽式反射镜的单轴调整主要服务于焦线聚光，设备空间呈较长的集热阵列结构。学习结果应能够说清光能在哪里被吸收、热量由何种工艺单元输送，以及后续通过什么设备产生蒸汽并驱动发电。

## 5. 槽式三维场景设备布置

在槽式三维场景搭建中，从已有设备库选择槽式聚光集热单元及相应辅助设备，完成集热部分与发电部分的布置。围绕集热回路、传热与换热设备、储热单元、蒸汽动力发电和供热制冷相关设备，识别每一单元的作用与空间关系。原有槽式内容保留设备参数设置与运行监控，学生可依据任务选择已开放的参数操作，再查看场景数据。具体跟踪结构、储热介质回路和设备位置限制应由已有软件场景决定，不使用未经确认的新设备扩充任务。

## 6. 储能设备的结构与用途认知

在储能认知部分，分别查看已有热储能、电储能和冷储能设备，结合设备结构说明储存能量形式及其输入输出关系。熔融盐储热罐主要保留高温热量，储热水箱储存水体热量，电池负责电能存储，储冷设施用于冷量缓冲。对制冷机组还应区分吸收式与蒸气压缩式的主要能量驱动方式。认知过程的目的不是强制把所有设备连接成新的综合系统，而是为原有自由搭建中选择适当设备和正确接口提供知识基础。

# 六、二维自由搭建与运行验证

## 1. 二维自由搭建中的设备选择

二维自由搭建以设备图标和接口组成系统拓扑。学生首先明确任务是塔式光热发电、槽式光热发电还是既有的某一储能应用，再从软件设备库中选择必需的聚光集热、储热、输送、换热、水汽动力及相关用能单元。原项目保留塔式、槽式及储能已有功能，但不意味着所有设备必须在一个联合新实验中同时运行。选型时应把设备作用与能源形式一一对应，避免误将定日镜、槽式聚光器、板式集热器和光伏组件混作同一种设备。

## 2. 工艺图标布置与拓扑结构

将已选设备图标拖入二维画布后，依据工艺流程安排其相对顺序。塔式可按定日镜集热、熔盐储热、换热、蒸汽发电和回水的逻辑排布；槽式可按槽式集热、传热与储热、蒸汽动力循环和热能利用的逻辑排布。储能支路则应明确其与热源、用热设备或电气系统之间的接口关系。设备排列仅用于表达拓扑，最终仍需逐条连接可用的端口、完成必要的参数配置，并通过实际仿真结果验证是否构成可运行系统。

## 3. 介质接口识别与连接校验

在建立二维工艺连接前，必须辨别不同设备的接口类型与能量传输方式。熔融盐、热水、给水、蒸汽、电气AC/DC以及制冷相关介质或能量侧，都应遵循软件对应设备提供的端口约束。不能因为图标可被拖放就把不相容的端口直接相连；对于有方向要求的设备，还应核对入口和出口关系。完成连接后应沿热源侧、动力侧、回路侧和储能侧逐段检查，重点排除漏接、断路、反接、跨介质误接和缺失必要换热或电能转换设备的问题。

## 4. 自由搭建参数配置与仿真运行

设备连通后，按实验任务打开已提供的参数配置界面，记录当前工况并输入软件允许调整的设备参数。运行前应核对参数的物理单位、合理范围及设备关系，例如热源供热能力、工质流量、储热状态和蒸汽动力需求之间不能相互矛盾。随后利用软件已有的运行控制执行仿真，并读取计算结果和图表。若结果异常，应依次检查设备选型、端口匹配、参数输入以及系统边界，而不是直接断言算法错误或临时新增未在系统中实现的控制功能。

## 5. 运行曲线与工况前后比较

运行曲线用于反映设备和系统指标随着模拟时间或工况变化的趋势。对塔式方案可重点结合聚光热源、储热状态、蒸汽动力侧及发电结果分析；对槽式方案可关注槽式集热回路、热量传递、储热与动力转换之间的关系；对储能应用则分别理解电量、热量和冷量的使用场景。比较不同工况时要保存或记录原有设置，在其它条件尽量一致的情况下调整一个可控变量并再次运行。具体曲线名称、算法和数值范围以软件实际显示为准。

## 6. 理论考核、评价与报告整理

完成认知、场景搭建和自由组态等任务后，可利用原有理论考核和评价功能回顾塔式与槽式聚光、热量转换、储能设备及接口匹配等知识。报告内容可包括设备识别记录、三维布局、二维拓扑、参数设置、仿真运行数据、曲线及评价信息。原软件已有理论考核、错题解析、实验评价和报告相关功能，但具体拆分版本的分值、评分细则和报告输出形式须以实际软件为准。不得因为知识库列有一项观察要点，就认定软件对该要点设置了独立自动判分规则。

# 七、结果解释与常见问题

## 1. 塔式与槽式的主要区别

塔式光热发电通过分布式定日镜将太阳直射辐射反射至高塔顶部的集中吸热器，典型定日镜采用双轴跟踪；槽式光热发电利用槽形抛物反射镜将光汇聚到沿焦线布置的吸热部件，通常采用单轴跟踪。二者在反射镜形状、跟踪方式、集热位置和场区布局等方面有所不同，但都可把热量送往换热、储热和蒸汽动力发电环节。教学中应先分别理解结构与流程差别，再认识共有的热量储存和朗肯循环原理；不要把“比较二者特点”误写成软件已有独立综合对比实验。

## 2. 为什么不能把所有储能指标直接比较

热储能、电储能和冷储能分别针对不同的可用能量形式，单纯的温度、SOC、冷水温差不能直接构成统一的容量指标。若需要理论比较，应先明确储存介质、储能容量、可用功率、时间长度、效率和边界条件，再采用一致的能量单位与定义。软件当前以原有储能设备结构、场景及自由搭建功能为依据，未要求增加新的跨储能系统量化对比模块。学生在结果分析中可阐明差异，但不能编造软件未输出的转换效率、经济性指标或最优排序。

## 3. 如何判断光热发电系统运行是否合理

评价系统合理性应结合聚光集热设备是否选对、传热与储热回路是否完整、换热侧与水汽侧是否对应、汽轮发电设备是否连接完整，以及参数和输出是否一致。若只有设备图标而缺少介质连接，属于拓扑不完整；若接口类型错误，即使图示连接形成闭环也可能不具工程意义；若参数超出边界，则需按软件允许范围重新配置。应把可观察的运行曲线与监测数据作为结论依据，不仅凭界面出现“运行中”或单个功率数值判断实验成功。

## 4. 项目组合与独立对比实验的界限

本项目的建设路径是复用原有塔式光热、槽式光热及储能相关功能并整合成一个申报项目，而不是在原有功能之外引入新的跨技术路线联合优化实验。知识库可以解释塔式与槽式的技术区别、总结储热或储电原理，也可以指导学生分别使用既有场景；但不应声称软件已经支持塔式槽式同时出力调度、自动生成横向性能排名、联合储能策略寻优或新的多工况综合对比实验。描述软件功能时应以既有操作入口和可核验结果为准。
